## 0. 使用说明与口径裁决

### 0.1 本文定位与范围分层

| 层 | 内容 | 是否进 Demo |
|---|---|---|
| **L1 · 可直接入库文本** | 每卡「一句话人设」（≤30 字）、「体系风味」（≤20 字）、**文化真名（玩家感知主名）** | ✅ 进 Demo（对应《框架接口》§5 待补字段；真名作为卡面主显示名，`cards.json.name` 保留为机制名） |
| **L2 · 美术落地包** | 视觉简报（主色 hex / 材质 / 剪影 / 冷暖 / 尺度反差对象 / ▲▣◆● 形状码） | ✅ 进 Demo（立绘外包必需，对齐《美术圣经》§2.2/§2.5） |
| **L3 · 全量愿景叙事** | 角色小传（200–400 字）、人生偏好、战斗包装、关系线索、群像设计 | ❌ 不进 Demo，服务 P1+ / 招商 / 招人 / 卡池运营 |

> **范围纪律**：《框架接口 v1.0》§8 Non-Goals 写明「Demo 不写角色小传」。本文 **L3 层刻意超出 Demo 范围**，因为它服务的是**商业化主轴（船员 Gacha）与 NFT 价值叙事**。L1/L2 才是 Demo 交付物，二者不冲突：**L1 是 L3 的压缩摘要**，同源不同粒度。

### 0.2 数据真源与不可篡改项（红线）

以下字段一律以 `cards.json` 为唯一真源，本文**只做叙事包装，不做任何改动**：

- `id`（角色 ID）· `name`（正式显示名 / 机制名，`_meta.name_ssot`）· `system`（体系）· `rarity` · `cost` · `atk/def/spd/hp` · `archetype` · `skill` · `strong_against` / `countered_by`
- 克制环：`烈焰 → 铁壁 → 疾风 → 潮汐 → 烈焰`，`RESTRAINT = 1.3`（硬约束）
- **`cards_hash = 5acbc0ef06de328e0bf10d19524665cd17fe64fe59821636ce1e0db82c4d5eb4` 保持不变**（锁定卡表摘要，见 `RULESET_LOCK.md §1`）。本次「文化真名」属 **L3 叙事层新增**，不写回 `cards.json`、不触碰任何身份字段（`card_id/system/rarity/cost/identity/skill.name/skill.type`），**不触发 `cards_hash` 重冻结**。
- 战斗护栏：`STAT_CAP{200,200}` · `MAX_STUN_ROUND=3` · `MAX_DOT_STACK=5` · `MAX_SHIELD_MULT=2.0` · `MAX_EXTRA_HIT=2` · `TRUE_DMG_ROUND_CAP_RATIO=0.08`
- **任何 C1 设计不得**：跨体系免疫 / 无视克制 / 突破 `STAT_CAP` / 修改已冻结常量（§12.5 红线 1、§11.1.3 护栏）

### 0.3 双层口径：神话是表层，技术是内核

《框架接口 v1.0》定基调为「零超自然、可推理」；《策划案 §13》与《世界观圣经》则要求「暗黑神话史诗」。本文用**双层口径**同时满足二者：

| 层 | 内容 | 作用 |
|---|---|---|
| **信仰层（表）** | 角色相信自己在侍奉祝融、海皇、寒神；世界遍布神像、祭坛、沉城 | 服务 §13「暗黑神话史诗」与 NFT 收藏欲 |
| **机制层（里）** | 每一个「神迹」都有工业或自然解释（火药、冶金、帆索、能量共振 = W1 四技术路线） | 服务支柱 1「胜负在出航前决定」——世界必须可推理 |

> **写作铁律**：角色可以**说**神话，叙述者**不能证实**神话。神明在本作中是「被信仰的解释」，不是「被验证的存在」。
> 由此顺带解掉 **N-Q1**（UR 命名东西方混用）：祝融之裔与波塞冬并非同一神系，而是**纪元 0「黄金彼岸」三文明对同一批远古现象各自命名的遗产**。混用不是 bug，是「大沉没打散了统一叙事」的证据。本文 v2.0 进一步将此口径扩展为**全部 20 个真名**的写作公约（见 §0.4）。

### 0.4 【v2.0 新增】文化真名层：万国混编的写作公约

> 本版核心升级：给每张卡新增「**文化真名**」（玩家感知主名），并建立「真名 ↔ 卡 ID ↔ 机制名 ↔ 体系 ↔ 稀有度」映射表（§1）。为确保这一层**不破坏世界观**，立三条公约：

1. **真名是「船员在酒馆里报出的名字」**。大航海时代（本作「纪元 II·漂流」）的船员本就来自被大沉没吞掉的各个文明碎片——瀚海、冻洋、渊海、信风带只是**当下聚落**，不是血统的全部。每张卡的**文化真名可来自与现实文化谱系对应的「失落文明」**（华夏燧人氏/祝融、波斯拜火、北欧铁匠与霜巨人、希腊海神与哲思、蒙古草原、日本风见、格鲁吉亚高加索、波利尼西亚航海），由角色个人经历赋予，而非由出生地机械决定。
2. **真名是 L3 层设定，不写回数据**。`cards.json.name`（如「火药学徒」）保留为**机制名**（卡面角标、图鉴机制栏、数据层主键引用仍用它）；**文化真名**作为**卡面主显示名**（立绘标题、剧情对白、图鉴人名栏）。二者同卡同源，缺一不可，**任何一处都不构成对数据层的篡改**。
3. **真名不替代、不推翻 v1.0 已锚定内容**。`FLAME_UR_01 祝融之裔`、`TIDE_UR_01 波塞冬·深渊之主` 两枚 UR 真名锚点**原样保留**（其机制名即真名，凡名佚失是设定，不是缺失）；其余 18 卡真名为 v2.0 新增层。

### 0.6 卡面 UI 接法规格（C-6 已定 · 2026-08-06）

> 本规格回答「真名 / 机制名 / 角色 ID 三层在 UI 上各显示在哪」——**纯文档规范，不依赖引擎**；渲染实现归 G2 定后的 Demo 工程。

**数据接法**
- 工程侧建**显示名映射表**（独立于 `cards.json`，L3 叙事层配置，不触发 `cards_hash`）：`card_id → { lore_name（真名）, mech_name（机制名）, archetype }`，真源 = 本文 §1 映射表。
- 映射表进 i18n 表（出海多语言：真名/机制名各语言一份），`card_id` 为全语言稳定主键。

**各 UI 显示规则**

| UI 位置 | 显示 | 说明 |
|---|---|---|
| 卡面立绘标题 | **真名**（主） | 例：燧生 |
| 卡面机制角标 | **机制名**（副，小字）+ archetype | 例：火药学徒 · 焚烧者 |
| 图鉴人名栏 | **真名** | 玩家检索按真名 |
| 图鉴机制栏 / 数据面板 | **机制名** + archetype + 技能 | 数值与机制语境 |
| 战斗单位名牌 / 演出对白 / 招募台词 | **真名** | 情感与叙事语境 |
| 数据层 / 链上 / 日志 / combo 关联 | **角色 ID** | 机器标识，永不显示给玩家 |

**边界**：`cards.json.name` 冻结不改；真名只存映射表；任何 UI 不得把 `FLAME_R_01` 这类 ID 直接暴露给玩家。

## 2. 设定模板（字段清单 · v2.0 版）

### 2.1 字段总表

每张卡的设定条目**固定 10 个叙事字段 + 2 个机制保留字段**，缺一不可。字段顺序即撰写顺序。

| # | 字段 | 规范 | 消费方 |
|---|---|---|---|
| 1 | **文化真名** | 玩家感知主名 + 语源/出处一句话（§1 表为准） | 全员 / UI |
| 2 | **角色 ID + 机制名** | `cards.json.id`（角色 ID）+ `cards.json.name`（机制名，照抄，不可自创） | 工程 / 数据层 |
| 3 | **体系 · 稀有度 · 卡 ID** | 四体系之一 + `rarity` + `id`，照抄 | 美术 / 战斗 |
| 4 | **文化原型与历史形象** | 对应哪个文化谱系、什么历史形象（考据感） | 美术 / 文案 |
| 5 | **一句话人设** | ≤30 字，可直接填 `cards.json.desc` | 工程 / UI |
| 6 | **角色小传** | 200–400 字：出身→转折→现在，与暗黑神话史诗基调共鸣 | 文案 / 运营 |

### 2.2 字段填写规范（硬约束）

- **命名**：文化真名由本文 §1 唯一指定，不得另造；`cards.json.name` 为机制名，**不得替代、不得改字**。角色绰号可在小传内出现，但不与真名/机制名冲突。
- **数值**：小传与偏好禁止出现具体数值（如「护甲 +25%」）；数值表达一律交给字段 8/12。
- **神明**：可写「他们说」「祭司称」「碑文记载」，不可写「神确实降下」。
- **阵营**：文化阵营须落在《世界观圣经》§3 的三海域 + 信风带之内，不得新增第五文化；文化真名的「失落文明」谱系按 §0.4 公约 1 处理，不构成第五文化。
- **尺度反差**：必须从 §1.6 参照物库中选定**具体对象**，禁止写「一个很大的东西」。
- **视觉简报**：主色必须引用《美术圣经》§2.2 **冻结 hex**；形状码必须含 ▲▣◆● 对应项（§2.5）；暖光源/冷环境切分须明确（`IRON_UR_01` 为唯一「无暖」例外）。

议会没有处置她。因为北风关十九年没破过。

十九年里她拒绝过四次调任，包括去永冻城的机会。有人问她图什么，她说她在等一个人接手，等了十九年没等到。大沉没之后，北风关塌了半边，她终于下了关口，上了船。

**角色小传（约 380 字）**

长夜岬是冻洋最北的海角，永夜里唯一的一盏灯在那里。守灯的人叫守望者，一任一生。

他不是守灯人。他是去接北风关的班的——塔玛拉等了十九年的那个人，就是他。他去了，站了一个冬天，看她如何分甲、如何算配重、如何在议会上顶回功勋子弟的抗议。然后他走了，一句话没留。

他去了长夜岬，在灯塔下给自己立了一块碑。碑上没有生卒，只刻了七个名字——是他在冰原上没能救回来的七个人。

冻洋人不懂。督战的位置是荣誉，守灯是苦役，他为什么选后者？他只对一个人解释过：**「她守的是一条线。线断了可以重新拉。我守的是一盏灯。灯灭了，回来的人就找不到岸。」**

他的甲是全冻洋最重的一副，重到他不能奔跑，不能上小船，只能站在原地。这不是缺陷，是设计——极昼台的老匠人为他做这副甲时说过：**「你要的不是活下来，是让打你的人后悔。」**

大沉没那天，长夜岬的灯没有灭。他站在灯下，从入夜站到天亮，甲上被砸出十七个凹坑。灯还亮着。

族谱上他的名字是比约恩——熊。冻洋人后来不再叫他名字，只叫「守灯的」。他无所谓。熊本来就不需要别人记得它的名字，只需要别人记得灯还亮着。

信风带上的孩子没有籍贯，只有航次。他的第一个航次是七岁，在别人船上当压舱的活重物。

压舱的人整天躺在最底舱，什么也看不见，只能听——听水从哪一面拍来，听帆索在哪一根上先绷紧，听船身在转向前那一瞬间的呻吟。躺了三年，他闭着眼睛能报出船正在往哪偏。

十岁那年，他在底舱喊了一声「右满舵」。没人理他。二十息后，船撞上了一块没标在海图上的礁。那之后，船长把他从底舱拎了上来，扔在船首，说：「你以后就待这儿。」

有人问他名字，他说萨拉哈，意思是风。问的人说，那你不就是没有名字。他说，风本来就没有名字，你叫它，它就来了。

她学了九年，从没共振成功过一次。

十二岁那年的考核，她被判定为「无共鸣者」，从沉光城的名册上划掉。按规矩，无共鸣者可以留在城里做杂役，一辈子安稳。她走了。

她走的时候带了一样东西：一把从遗迹里捡的旧弩，机括是纪元 0 的样式，早就没人会用。她花了四年把它修好，又花了两年学会在船上射中东西——海上的风会让箭偏，偏多少取决于风速、湿度和你自己的心跳。

这是可以算的。这一点让她着迷：**风不需要你共鸣，风只需要你算对。**

她给自己取名「风见」——风向标。亚特兰蒂斯人不明白：名字应该是祭司赐的、刻在名册上的，怎么可以自己取。她说不刻在名册上的名字才是自己的。

她后来回过一次沉光城，站在城外没进去。她听见里面还在吟诵，声音和九年前一模一样。她拉了一次弩，射断了城门外一根系着祷幡的绳子，然后转身走了。

**角色小传（约 360 字）**

信风带没有法律，只有一条共识：**先到的人先拿。**

他从十九岁起就活在这条共识里。别人跑贸易讲究稳，他讲究快——他把船上所有能扔的都扔了，包括压舱石、包括备用桅、包括一半的淡水。他的船轻得在浪里像一片叶子，也快得没人追得上。

他没有回头。按信风带的共识，他没有错。

那之后他还是最快的，但他不再扔压舱石了。有人问他为什么，他说重一点没关系，反正也没人追得上他。这句话他说得很轻松，说完就转身去看帆了。

他叫朝鲁，蒙古古语里是「石头」。草原人的祖先骑马，信风带的人行船，但道理是一样的——**跑得最快的人，往往背着最重的东西。**

**角色小传（约 400 字）**

高加索的少年在北风关服役三年，才有资格领自己的第一副甲。他服满了三年，在领甲那天当着长老的面把甲还了回去。

理由他只说了一句：**「甲挡得住一次重击，挡不住一百次轻击。我在关上数过。」**

议会认为这是对氏族三代冶金的侮辱。他被逐出族谱，名字用凿子刮掉——高加索的规矩，刮痕要留着，让后人看见。

他去了信风带。信风带的人不问出身，只问你能干什么。他能干的事很奇怪：他不学怎么跑得更快，他学怎么在跑得快的时候**打同一个点**。三年里他跑遍了整条信风带，跟每一个愿意教他的人学攀索、学配平、学在船身摇晃时保持手不抖。

二十九岁那年，他一个人拆了南洋渡外海一艘重甲护航船。他没有攻破它的甲——他在船身同一个铆接点上凿了三十七次，甲从内部裂开了。围观的人说那是「破阵」。这个词后来成了他的名字。

他没有回过冻洋。但每年冬天，他会在信风带最北端停一晚，朝着永冻城的方向站着，一整夜不动。

那是高加索人的站姿。他没忘。

族谱上那个被刮掉的名字是格里姆——蒙面者。刮痕旁边没有人补写过别的字。信风带的人叫他破阵，冻洋的旧识叫他格里姆。他两个都答应，两个都不算数。

**战斗包装（性格/身世 → 战斗定位）**

**角色小传（约 410 字）**

信风带的引水人有一条不成文的规矩：**不标追风之翼。**

原因很实际——标不住。三海域的航海记录里有一百四十余次目击，每一次的位置都不同，每一次的时间间隔都短到不可能是同一条船跑过去的。有人算过，若真是同一个存在，它的速度需要超过任何已知船只的四倍。

这是说法。可以查证的部分有三条：其一，每次目击前后，当地的风场会出现**持续约半刻的异常**——风向不变但风速陡增，帆索会发出一种极高的音；其二，一百四十余次目击中，有六十余次发生在**有人即将沉船的位置**；其三，那六十余次里，沉船的人**都活下来了**。

信风带的人因此有两种说法。一种说他是纪元 0 长桥断裂时被卷进风里的信使，至今还在送最后一封信。另一种说法更简单：他不是在救人，他只是**恰好在跑**，而海太小了。

追风之翼从未与任何人交谈。所有目击的共同点只有一个：**你先听见风，然后什么都来不及。**

信风带最北端的岩壁上刻着一行字，据说是某位老引水人临终前刻的：**「他不是风。风只是他跑过去以后留下的东西。」**

**人生偏好**

- **性格关键词**：非人 · 永不停止 · 无意图的救赎 · 与人无涉 · 曾经是人
- **习惯癖好**：无（不可观测）；唯一可观测的「行为」是风场异常总是出现在「有人即将沉船」的位置——如果那是行为的话
- **喜好 / 厌恶**：无（不可观测）；信风带的人相信他「厌恶停下来」，因为他从未被目击停驻——但这也可能是观测偏差
- **口头禅 / 说话风格**：不说话。唯一「语言」是帆索发出的那种极高音——先听见风，然后什么都来不及

**战斗包装（性格/身世 → 战斗定位）**

它没有攻击任何人。它浮出海面的那一刻，整个渊海的能量井同时亮起，所有正在燃烧的火同时变弱，所有正在共振的频段同时对齐。祭司们跪了下去。特里同没有跪，因为他终于听清了——**这个声音，和他四十年来一直在回答的那个，不是同一个。**

它至今没有说过一句话。

> 供战斗演出、图鉴文案、配音脚本直接引用。原则：**克制环即性格冲突环，反制即协同**（§2.3）——互克的两人同队，对白要写成「互相看不惯但背靠背」。

**① 火墙（铁壁 + 烈焰，跨体系 combo）**

**② 锁定爆发（潮汐 + 疾风，跨体系 combo）**

**③ 烈焰互燃 chain（燧生 → 阿达尔 → 灼华 → 祝融之裔）**

- 布洛克：「站着。」
- 沈百炼：「你站我旁边就行。」——三个人三句话，叠甲三层。

**⑤ 疾风抢速链（萨拉哈 + 风见 + 朝鲁）**

- 风见：「风速三，湿度七。」
- 朝鲁：「先到的人先拿。」——三个人三句话，一个回合的事。

**⑥ 潮汐控链（卡戎 → 狄奥提玛 → 特里同 → 波塞冬）**
