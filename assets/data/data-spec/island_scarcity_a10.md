# A-10 · 多人化岛屿稀缺（island scarcity）

> **作者**：游承峰（主理人） · **日期**：2026-08-02 · **关联**：`COMPILATION-REPORT.md §4`（A-10 行） / `10-经济 §8 A-10`（❌ 推翻） / `asset-ownership-boundary.md §4 A-10` / `GDD-02`（占岛）
> **状态**：⚠ **A-10 被推翻（这是真问题，需玩法解）**；本文件落成**联盟共治方案的可合入数据结构与分配规则**。
> **性质**：玩法风险 → 解法设计；**P1 阻塞（多人化前 Must），Demo 不阻塞**。

---

## 0. 一句话

岛屿硬上限（Demo 12 / 全量 36）+ 每岛唯一归属，在多人环境下会使**绝大多数玩家占不到岛、护岛经济对他们失效**。解法 = 回到世界观原设定：**岛屿由"联盟"而非"单人"护岛**（联盟共治）。

---

## 1. 问题量化（10-经济 §8 A-10）

| 场景 | 岛/人 | 护岛经济覆盖率 |
|---|---|---|
| Demo 单人 | 12 / 1 | 100% |
| 100 人同服 | 36 / 100 | **≤36%** |
| 1000 人同服 | 36 / 1000 | **≤3.6%** |

> 护岛经济是 Demo 的"第二 faucet"（日产），若只对 ≤36% 人有效，其余人失去核心进度来源 → 玩法不可持续。

---

## 2. 解法对比（10-经济 §8 三选一）

| # | 解法 | 对链上结构影响 | 评价 |
|---|---|---|---|
| 1 | **联盟共治**（世界观已支持） | `mapping u8 => address` → `mapping u8 => alliance_id`；新增联盟程序 | **推荐**：回到原设定，单人占岛才是 Demo 偏离 |
| 2 | 分服 / 分片 | 岛 ID 加 shard 维度 | 大，且割裂社区 |
| 3 | 岛屿分层（核心唯一 + 外围驻点多人对存） | 大 | 保留稀缺感但结构复杂 |

**本人推荐解法 1**：世界观圣经 §7.1 写的就是"占领岛屿的**联盟**成为护岛者"——单人独占本来就不是原设定。当前"单人占岛"是 Demo 简化带来的偏离。

---

## 3. 联盟共治数据结构（可合入）

```leo
// 原（单人）：mapping island_id: u8 => owner: address;
// 改（联盟）：
struct Alliance { id: u32, members: u32, treasury: u64 }
mapping island_id: u8 => alliance_id: u32;     // 岛归属联盟
mapping alliance_id: u32 => Alliance;          // 联盟状态
```

- **分配**：岛屿在赛季初按联盟规模/战力预分配（避免后来者无岛），或开放"联盟夺岛战"（P1+）。
- **日产归属**：`ISLAND_DAILY_YIELD=120` 仍按岛结算（A-07 公式不变），但产出进入**联盟金库**，由联盟按贡献分配成员 → 护岛经济对**联盟全体成员**有效，覆盖率回到 ~100%。
- **稀缺度 vs 产出**：核心岛（高 tier）唯一、产出高；外围驻点（解法 3 可选）可多人共存、产出低。稀缺感保留在"核心岛争夺"，产出普惠在"联盟共享"。

---

## 4. 与 A-07 / 闸门 D 的协同

- A-07 的日产纯函数 `yield_i = f(ISLAND_M[i], dev_i, adj_owned_i, k)` **全部链上可读**，联盟共治不改变公式，只改变 `owner` 的语义（address → alliance_id）。
- 闸门 C（占岛归属原子事件）仍成立，只是事件主体从个人变联盟。
- Demo 的 12 岛单人模式**完全不受影响**，本方案仅对 P1+ 多人化生效。

---

## 5. 工程合入待办（P1+，多人化前 Must）

1. 新增 `Alliance` struct + `alliance_id` mapping（替换 `owner`）。
2. 联盟创建 / 加入 / 退出程序（含成员上限、踢人规则）。
3. 岛屿日产写入联盟金库 + 按贡献分配逻辑（可复用 `DECAY(k)` 衰减）。
4. 联盟夺岛战（P1+ 后期，承接 GDD-02 反目标"不做 PvP 夺岛"——多人化后需放开）。

> **边界**：Demo 阶段（12 岛单人）不实现本方案，A-10 不阻塞 Phase 3 进入；但**多人化前必须有定论**，否则护岛经济坍塌。
