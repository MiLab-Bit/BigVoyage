### 3.4 音频（阮和鸣）— 方向超水位，规格空白
- P0：①SFX 事件清单（寄生《规格层》§6.1 BattleLog：`deploy/skill/hit/dot/control/combo/down/end`+`sys`+`restraints`+`t(ms)`，命名 `sfx_btl_<type>_<sys>`）；②自适应状态机（intensity 0–3、≤5s ramp）；③gacha 仪式音（主付费点 0 规格）；④中间件解耦。
- P1：混音规范（−16 LUFS 移动 / −18 PC / ducking / 同发上限）；3–5 首参考锚曲；四体系动机谱例 + C1 变奏模板。
- 音频圣经骨架九章：听觉定位｜曲风参考｜音色板落地｜状态机｜SFX 清单｜Leitmotif/C1｜混音预算｜VO 与本地化｜实现命名与交付。
- **引擎耦合警示**：若最终落 Web/Canvas 链游，Wwise 无官方 Web runtime、FMOD HTML5 受限 → 音频圣经需写**双轨规格**（A: Wwise/FMOD@Unity；B: WebAudio@Web），共用事件清单与总线树。

### 3.5 商业化发行（路远行）— 近乎空白，NO-GO
- P0：①**法域二选一**（弃境内 / 仅出海）写入 SSOT；②**双轨分包**（链下法币 IAP 版 ‖ 链上 Web3 版）解耦变现；③概率终值+公示+保底进度 UI；④未成年人合规包（实名/防沉迷/限额）；⑤Apple/Google 预审；⑥ruleset 版本化 + 热修/链上迁移回滚预案。
- P1：首发 2–3 市场 GTM 包；本地化流水线与字符串冻结；Live Ops 手册 + 经济告警；社区与危机沟通。
- P2：KYC/AML/VASP 与税务；DAO 法务；VO 与深度本地化；回流留存。

**合规风险摘要（最高暴露）**：法币↔ERC-20 固定汇率 + P2P 场外所 + 回购销毁 + 治理币 → 中国 924 通知非法金融活动（境内有刑责）；含代币/NFT 链游无版号获批先例；无实名/防沉迷；Apple 3.1.1（购币须 IAP、NFT 不得解锁功能）、Google 区块链政策 → 现链路上不了双端；证券化(Howey)/EU MiCA/KYC-AML。

## 5. 升级路线图（分阶，含依赖）

```
G1法域 ─┐
        ├─(决策)─→ Phase A 决策闸闭合（写进 SSOT 二次冻结）
G2引擎 ─┘
                      Phase B 矛盾清零（quality-lead，14 项，基本独立于 G1/G2）
                            │
        ┌───────────────────┼────────────────────┐
   Phase C 美术圣经      Phase D 发行合规       Phase E 数值真机验证
   (art，依赖G2)        (release-ops，依赖G1)   (eng/quality，依赖G2+链环境)
        │                      │                      │
        └──────────────────┬──┴──────────────────────┘
                     Phase F 文档治理（CHANGELOG/索引/owner/命名/占位统一）
                            │
                     SP 级二轮回标（团队重审）
```

- **Phase A（决策闸）**：用户定 G1/G2 → SSOT 二次冻结。**不依赖任何文档工作。**
- **Phase B（矛盾清零）**：14 项矛盾裁决回写 + 裁决登记册 + 证据纳库。**可立即启动，大部分项不依赖 G1/G2。**
- **Phase C（美术圣经）**：依赖 G2。独立九节圣经 + hex 色板 + 资产规格。
- **Phase D（发行合规）**：依赖 G1。合规风险评估 + 双轨分包 + 概率公示 + 未成年保护 + GTM + 本地化 + Live Ops + 发布/回滚预案。
- **Phase E（数值真机验证）**：依赖 G2 + 链环境。Demo 接真机 playtest 补 M1–M7 实证。
- **Phase F（文档治理）**：CHANGELOG/索引/owner/文件名规范/占位统一。
