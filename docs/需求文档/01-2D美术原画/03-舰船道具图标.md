# 01-03 · 舰船 / 道具 / 图标需求（Godot）

> 上游：美术圣经 §6 · §2.5 形状码 · 商业化稀有度色

---

## 1. 舰船 2D Sprite · P0 至少木筏+铁壁重甲

| 舰型 | 命名前缀 | 视角 | 战损 | 备注 |
|---|---|---|---|---|
| 木筏（起点） | `ship_raft` | 侧+俯 | 完好/中/重 | P0 |
| 冰砌重甲舰 | `ship_iceheavy` | 侧+俯 | 3 态 | P0（冻洋） |
| 楼船巨舰 | `ship_lou` | 侧+俯 | 3 态 | P1 |
| 悬浮舰 | `ship_hover` | 侧+俯 | 3 态 | P1 |
| 混合帆船 | `ship_hybrid` | 侧+俯 | 3 态 | P2 |

**单舰文件集**（例冰砌）：

- `ship_iceheavy_side_ok|mid|wreck.png`  
- `ship_iceheavy_top_ok|mid|wreck.png`  
- 源 2048 → 游戏 1024/512；含**帆索层**（可单独 `*_sail` 透明层供摆动）。

Godot：`Sprite2D` 多层（船体/帆/旗）；战损用 `frame` 或换贴图。旗幟颜色绑主权/体系。

---

## 2. 角色标志道具 · P1（可与立绘一体交付）

每卡 1–2 件独立道具图（图鉴旋转展示）：`prop_<ID>_01` 1024 源 / 512 导出。  
清单见美术圣经 §6.2（火折子、塔盾、无指针罗盘、铭文石板等）。  
**禁止**与立绘冲突的重设计。

---

## 3. 世界资源 / POI 图标 · P0（经济可见）

| 资源 | 命名 | 色锚 |
|---|---|---|
| 战略资源（琥珀/软币表现） | `icon_res_strategic` | 羊皮/铜 |
| 航海晶 `$TIDE` | `icon_res_tide` | 紫金 `#B98BFF` |
| 寒铁 / 星银 / 丝绸 / 硝石 / 鲸脂 / 冰晶 | `icon_res_<name>` | 圣经 §6.2 hex |
| POI 类型 | `icon_poi_crew|ship|resource|event` | 形状码可读 |
| 主权旗 | `icon_flag_owned|enemy|neutral` | — |

尺寸：源 256 → 游戏 128；Godot `TextureRect` / 富文本 `img`。

## 5. Godot Atlas

建议 TexturePacker / Godot `AtlasTexture`：  
- `atlas_ui_icons.tres`（体系+资源+状态）  
- `atlas_ships_frozen.tres`（冻洋舰）  
编队与海图高频图标进图集，立绘**不要**打进同一 atlas。
