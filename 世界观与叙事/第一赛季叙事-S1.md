## 1. 核心主题与情感曲线

### 1.1 一句话母题
**「洋流不是路，是海在挑选谁配做它的孩子。」**——S1 要回答的，是幸存者从「被洋流抛弃的漂流者」变成「被洋流托付的顺流者」的身份转变。

### 1.2 三大主题
1. **馈赠与代价**：洋流给岛、给资源、给潮汐之核，但每一次馈赠都指向同一句警告——共主时代因贪婪抽取潮汐之核而沉没。S1 把「欲望 vs 节制」埋进每一次占据与征税。
2. **离散与重连**：36 岛本是共主一体，大沉没使其离散。S1 让三海第一次「隔海相望」，为纪元 V「长桥重连」埋最长线伏笔。
3. **顺流者得救，逆乱者没渊**：海皇先驱不判善恶，只判「是否顺应潮汐之道」。这把世界观里的「洋流不可违」上升为道德律。

### 1.3 情感曲线（七章）
`苍凉`(余烬) → `惊喜`(馈赠) → `张力`(初鸣) → `求索`(觉醒) → `不安`(低语) → `壮烈`(先驱) → `余韵`(归航)
- 设计意图：前 2 章建立安全感（洋流是善意），中段 3–5 章逐步撕开不安（海皇归来是清算），末 2 章以「协作壮烈 + 平静余韵」收束，避免纯黑暗结局，给续季留希望。

## 2. 三层戏剧冲突

| 层级 | 冲突 | 载体 | S1 落点 |
|---|---|---|---|
| L1 人与海 | 漂流者 vs 洋流无常 / 失落守卫 | PVE 占岛 / POI | Ch2 首占岛，Ch4 核心岛★不可占之挫败 |
| L2 海与海 | 三海域隔海张力 / 资源之争 | GVG / 贸易博弈 | Ch3 三海初鸣，Ch6 跨海域征战 |
| L3 海与神 | 幸存者 vs 海皇先驱（清算 vs 试炼） | 大型世界 Boss | Ch6 全服合力应对「试炼」 |

> 三层在 Ch6 汇流：玩家既要并肩对抗海皇先驱（L3），又要在此过程中第一次真正跨海协作（L2 转化），而这一切的根是「顺流者方能得核」（L1 的洋流主题）。

## 3. 角色谱

### 3.1 玩家（你 = 顺流者船长）
- 身份：本海域出生的幸存者，开场是木筏上的无名船长，赛季末成为「首占岛者 / 潮汐之核持有者的同盟一员」。
- 自定义：海域（高加索/亚特兰蒂斯/中华）、船名、旗帜；战斗靠抽到的**船员卡**（卡牌体系，商业化 §4.11）。
- 叙事功能：玩家是「观察者 + 参与者」，剧情不替玩家做道德抉择，但环境会奖励顺流行为（如占岛后克制税收≤5% 会触发 NPC 好感）。

### 3.2 三海 NPC 领袖（每位玩家出生海域对应一位，引导主线）
| 海域 | 领袖 | 原型 | 声音特质 | 主线职责 |
|---|---|---|---|---|
| 冻洋·高加索 | **霜须长老·瓦兰** | 铁壁重装将 / 氏族议会长老 | 低沉、短誓词、重荣誉 | Ch1 唤醒罗盘；Ch4 主张「逆风者方配永冻城」 |
| 渊海·亚特兰蒂斯 | **潮音祭司·伊澜** | 潮汐咒术将 / 祭司—学者 | 吟诵体、流音符号、神秘 | Ch4 破译铭文揭示大沉没真相；Ch5 听见先驱低语 |
| 瀚海·中华 | **市舶使·沈娘** | 烈焰火器将 / 市舶司使 | 通商口吻、楹联、务实 | Ch2 教贸易；Ch6 主导三角贸易「寒铁→星银→丝绸」 |

### 3.3 反派 / 威胁
- **海皇先驱（The Tideborn Herald）**：S1 大型 Boss。非传统邪神，而是「潮汐之道的执行者」——初临时以「试炼」姿态考验全服。台词内核：「吾非来焚，乃来选。顺流者得其核，逆乱者没于渊。」
- **失落守卫**：岛屿外围 PVE，休眠→苏醒（Ch3 起），是占岛前置，无台词，靠行为叙事（碑文/残骸）。
- **海域级巨兽**（中型 Boss ×4）：霜噬巨鲸 / 星渊利维坦 / 蜃楼巨鲲 / 怒涛海蛟，按海域与周次轮换，是「被顺流唤醒的古老之物」。

### 3.4 中立 / 功能性
- **自由航海者**（散人玩家群体）：不与联盟强绑定，Boss 协作方，叙事上代表「无旗之海」的浪漫。
- **潮汐罗盘**（道具/UI 角色）：拟人化叙事道具，Ch1 苏醒、Ch7 仍指向远方——承担「旁白」功能，少量 VO 由其口吻念出。

## 5. 剧情大纲（核心交付物）

> 每章含：场景清单 / 剧情节拍 / 关键台词（示范）/ 钩子 / 玩法咬合。
> 节拍标注：`[过场]` 演出、`[事件]` 世界事件、`[玩法]` 触发系统、`[抉择]` 轻量选择。

### ▌第一幕：漂流与馈赠（Ch1–Ch2）

#### 第 1 章 · 余烬与罗盘（备战 D1–2）
- **场景清单**
  1. `[过场]` 序章：苍蓝海面，三海木筏剪影，画外音（潮汐罗盘）：「沉没之后，第一千个冬天。他们以为洋流忘了他们。」
  2. `[玩法]` 新手引导：选海域、命名船、领首张 N 卡船员（霜须/伊澜/沈娘配音引导）。
  3. `[事件]` 所有木筏的潮汐罗盘同时亮起，指针稳指洋流下行。
  4. `[过场]` 三屏分镜：高加索瓦兰按剑、亚特伊澜吟诵、中华沈娘展图——异口同声：「海皇在指引我们。」
- **节拍**：孤独 → 异动 → 指引。结尾留「罗盘指向的不是岛，是某段被遗忘的航路」。
- **关键台词**（瓦兰）：「逆风者不惧寒。可今夜，连风都顺了——这比风暴更叫人不安。」
- **钩子**：罗盘指针尽头，海平线有一道「不属于任何岛」的微光。
- **玩法咬合**：解锁自动航线（洋流）、体力 POI 入口、环境主题「顺流盛行」生效。

#### 第 2 章 · 顺流而下的馈赠（漂流 D3–8）
- **场景清单**
  1. `[玩法]` 前 5 天顺流靠最近岛（霜牙/明州/星渊），消耗体力探索 POI。
  2. `[事件]` 世界播报：「三海同时靠岛——顺流之馈，第一次兑现。」
  3. `[玩法]` 击败外围失落守卫 → 首占岛 → 获「首占岛者称号」（S1 大奖）。
  4. `[玩法]` 迷雾裂隙 POI 掉落可上链船员卡（1/480，Free2Play 路径）。
  5. `[过场]` 占岛夜：营火旁，沈娘（中华线）递来第一匹丝绸：「贸易，从这缕线开始。」
- **节拍**：惊喜 → 占有 → 微醺的满足。中段开始有「守卫在远处睁眼」的不安预告。
- **关键台词**（伊澜，亚特线）：「星银不是矿，是海流的记忆。你挖走的，是它的低语。」
- **钩子**：玩家占岛后，地图边缘的 Tier3 岛守卫「睁了一下眼」又睡去——为 Ch3 苏醒埋线。
- **玩法咬合**：占岛规则（§4.2，税收≤5%）、POI 产出（经济 §1.1 ÷24）、NFT 概率（1/480）。

### ▌第二幕：觉醒与张力（Ch3–Ch5）

#### 第 3 章 · 三海初鸣（觉醒·前 D9–13，中型 Boss #1）
- **场景清单**
  1. `[事件]` 岛屿守卫正式苏醒，更高 Tier 岛活跃。
  2. `[过场]` 云图浮现「信风之路」——横跨三海的洋流古道，旁白：「共主时代，三海本是一条路。」
  3. `[玩法]` **中型 Boss #1**（霜噬巨鲸/星渊利维坦/蜃楼巨鲲 按海域轮换），全服协作。
  4. `[玩法]` 联盟雏形：玩家结盟（§4.6）。
  5. `[抉择]` 轻量选择：占岛后税收设 2% / 5%？选低触发 NPC 好感 +（叙事奖励顺流之道）。
- **节拍**：张力升起 → 第一次「我们 vs 巨兽」的协作快感 → 三海第一次意识到彼此。
- **关键台词**（瓦兰）：「巨鲸吞得下船，吞不下旗。今日，三海同旗。」
- **钩子**：信风之路尽头，三海交界处有「一座谁都不敢占的中立岛」轮廓。
- **玩法咬合**：中型 Boss 频次 D4（×4/赛季）、四体系克制初显（卷五 §5.2）。

#### 第 4 章 · 觉醒之潮（觉醒·后 D14–18，中型 Boss #2）
- **场景清单**
  1. `[玩法]` 护岛者经济开放：产出规划、税收、贸易港（同海域）。
  2. `[过场]` 三座核心岛★（永冻城/亚特核心/华夏枢）在洋流尽头浮现，守卫极强，不可占。
  3. `[玩法]` **中型 Boss #2**。
  4. `[过场]` 伊澜在铭文礁破译：投影出大沉没真相——共主时代抽干潮汐之核，海皇震怒，大陆崩裂。
  5. `[抉择]` 玩家读到铭文后的反应（「敬畏」/「贪婪」分支文案，不影响数值，只改 NPC 评语）。
- **节拍**：繁荣 → 敬畏（真相） → 隐忧。核心岛不可占制造「看得见够不着的」焦虑，留 S2。
- **关键台词**（伊澜）：「他们不是被海皇毁灭的。是他们先把手伸进了海的心脏，海才合上了眼。」
- **钩子**：铭文末句：「潮汐将归，先驱先行——它来，不是为了沉没，是为了挑选。」
- **玩法咬合**：核心岛★产出/税收（世界观 §4）暂锁；科技 T1–T2；贸易预热（§4.3）。

#### 第 5 章 · 潮汐的低语（潮汐复苏·前 D19–21，中型 Boss #3）
- **场景清单**
  1. `[过场]` 全服梦境过场：所有船长听见同一低语（先驱 VO）。
  2. `[事件]` 跨海域通道「将开未开」，三海第一次听见彼此潮声。
  3. `[玩法]` **中型 Boss #3**（末段威胁）。
  4. `[玩法]` 跨海域侦察（§4.7 预览），高难 POI 凸显组合技（将+船体+环境）。
- **节拍**：不安 → 预感 → 集结。环境主题「顺流盛行」临近尾声，氛围转冷。
- **关键台词**（先驱 VO）：「潮汐将归，顺流者得其核，逆乱者没于渊。你们，准备好了吗？」
- **钩子**：梦醒时，每位玩家的潮汐罗盘多了一道「指向深渊」的细纹。
- **玩法咬合**：跨海域通道 Ch6 才正式开；中型 Boss #3。

### ▌第三幕：潮汐复苏与归航（Ch6–Ch7）

  5. `[玩法]` 跨海域征战正式开启（§4.7），三角贸易成型（星银硬通货）。
  6. `[抉择]` Boss 末段：击退（武力）or 安抚（献上潮汐之核共鸣）？两种结局文案不同，奖励相同。

- **关键台词**（先驱，降临时）：「吾非来焚，乃来选。顺流者得其核，逆乱者没于渊。」

- **玩法咬合**：大型 Boss D4（纪元IV ×1）；潮汐之核 NFT（世界观 §6）；跨海域贸易（§4.3/§4.7）。

#### 第 7 章 · 顺流之馈·归航（结算 D29–30）
- **场景清单**

  2. `[玩法]` 结算：发放 S1 大奖、排名结算。
  3. `[玩法]` 奖励回收（d_recycle 500/天）；跨季继承（D1：科技留/NFT 留/资源 50%/地图排名重置）。
  4. `[过场]` 收束：罗盘仍指向更远黑暗，瓦兰/伊澜/沈娘各留一句 S2 预告。
- **节拍**：余韵 → 平静 → 开放结尾（希望 + 悬念）。
- **关键台词**（沈娘）：「这一季，我们学会了顺流。下一季，该学会，如何不被潮水带走同伴。」

- **玩法咬合**：继承规则（§3.6）、资源 50% 软上限、d_recycle（经济 §4）。

## 6. 重点场景脚本（示范，含台词）

### 场景 A · 序章「第一千个冬天」（Ch1 开场过场）
> 【画面】极夜海面，三叶木筏在碎冰间漂。字幕：纪元 II·漂流，终。
> 【VO·潮汐罗盘】沉没之后，第一千个冬天。他们以为洋流忘了他们。
> 【画面】罗盘灯骤亮，指针旋转后稳稳指向右下方洋流。
> 【VO】可今夜，所有的罗盘，同时想起了回家的路。
> 【切】三屏：高加索风雪中瓦兰抬头 / 亚特幽蓝里伊澜睁眼 / 中华港口沈娘展图。
> 【三人同帧·混音】「海皇……在指引我们。」
> 【黑场】S1 · 顺流之馈。
