# 01-02 · 场景 / 环境 / 海图需求（Godot）

> 上游：美术圣经 §5 · 世界观 · `islands.json`（Demo 12 岛 FR_*）  
> 引擎：海图 `Node2D` + 视口拖拽缩放；滤镜用 `WorldEnvironment` / `CanvasModulate` / 自定义 `canvas_item` shader。

---

## 1. 海域环境滤镜（env_bias）· P0 先做冻洋

| 海域 | ID 前缀 | 环境光主色 | 天气 | 标志元素 | Demo |
|---|---|---|---|---|---|
| 冻洋 | `frozen` / G* | 冰裂灰蓝 `#8FA9BE` | 永昼风雪 | 冰砌堡垒、鲸骨、灯塔 | **P0 全做** |
| 渊海 | `abyss` / A* | 紫黑`#3A2E5C`+幽蓝`#3FA9C9` | 深层发光 | 水晶建筑、铭文 | P1 |
| 瀚海 | `hanhai` / H* | 暖橙`#E8A35C` | 季风黄金时 | 楼船、港口 | P1 |
| 信风带 | `tradewind` | 风暴青白`#C7DDE0` | 风暴 | 混合帆、浪墙 | P2 |

**每海域交付**

| 资产 | 命名 | 规格 | Godot |
|---|---|---|---|
| 滤镜 LUT/参数表 | `env_<sea>_bias` | 色温/饱和/对比/雾色文档 + 可选 3D LUT 纹理 16³ | `Environment` Adjustments 或 shader uniform |
| 海图底板 | `env_<sea>_chart_base` | 3840×2160 概念 → 2048×1152 游戏 | `Sprite2D` / 大图分块 |
| 迷雾层 | `fx_mist_<sea>` | 1024 可平铺 +alpha | `Sprite2D` 或 `GPUParticles2D` |
| 天气粒子贴图 | `fx_weather_<sea>` | 雪/雨/微粒 256–512 | `GPUParticles2D` |

切换：≤1s 渐变（Tween 改 `CanvasModulate` / shader 参数）。

## 2. Demo 12 岛（冻洋 FR_01–12）· P0

| 分级 | 需求 | 数量策略 |
|---|---|---|
| 出生近岛 | 母版概念 1 + 变体色/摆件 2–3 | 复用模板 |
| 中期岛 | 每岛 1 张概念 + 1 俯视图标 256–512 | 可共用建筑模块 |
| 重岛/Boss（含 FR_12） | **独立概念** + Boss 场竖构图 | 不可模板糊弄 |
| 岛图标（海图点击） | `env_island_FR_##_icon` | 圆形/徽章风，含主权旗插槽 |

**每岛交付包**

1. `env_frozen_FR_##_concept` 16:9 概念  
2. `env_island_FR_##_icon` 海图图标（未占/已占/敌占 三态可用换色）  
3. POI 点位装饰小图（可选 P1）：遗迹/资源点 64–128  

全量 36 岛：按美术圣经 §5.2 Tier 策略扩产（出生复用 / 圣城 G12·A12·H12 各 1 完整概念）。

## 3. 迷雾规格 · P0

- 半透明粒子层，**非**全黑遮罩；未探：高密度冷灰蓝 `#9AA3AB`；已探：降密度露主色。  
- 可透出下一目标剪影（塔尖/巨兽/浮岛）。  
- POI 裂隙：幽蓝 `#3FA9C9` 微扰。  
- Godot：`Light2D` 开雾 或 自定义 mask 纹理 + 玩家探索多边形。

## 5. Godot 场景建议

```
SeaMap (Node2D)
├─ ChartBase (Sprite2D)
├─ Islands (Node2D) … IslandButton (Area2D + Sprite2D)
├─ FogLayer (Sprite2D / ColorRect + shader)
├─ Weather (GPUParticles2D)
└─ UILayer (CanvasLayer) → 见 06-UI
```

滤镜：根节点挂 `CanvasModulate` 或全屏 `ColorRect` shader 读 `env_bias`。
