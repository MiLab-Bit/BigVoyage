# R1 烈焰主导诊断 · 跨守卫实测（主理人, 2026-08-02）

> **结论先行**：原 `r1_balance_verification.md` 给出的"R1 验证 FAIL / 需整体重平衡"是**基于一个误判的验收判据**。
> 实测证明：**烈焰不是全局主导策略**，所谓"99.9% 必选"只是"对铁壁 B3 守卫的单匹配克制"被误读成了全局主导。
> R1 不需要为重平衡服务；其真实价值（UR 卡数值垫底的商业风险）独立成立。原验收子判据应退役/重定义。

---

## 1. 三维 / 四维扫描回溯

复刻锁链测量协议（gm=1.15, hm=1.35, cap=0.80, seg=0.40, def_coef=0.30(D13②) + R1 独占全开），引擎基线自校准 = **6.73% / 97.4%**（R1-on 全量口径，与 `sim_r1_ur.py run(True)` 精确一致）。

- **三维扫描（flame_atk × flame_dot × 克制系数）**：80 网格点，**通过数 = 0**。
  规律：削烈焰 → FR_12 迅速跌破 5% 地板（最低 2.47%），而烈焰胜方占比始终 97~99% 不动。
- **四维扫描（+ 非烈焰 atk/def buff 轴 nfb）**：40 网格点，**通过数 = 0**。
  反常但关键：调高 `nfb`（buff 非烈焰）反而**降低** FR_12（7.40%→3.67%），烈焰占比仅从 99.1%→96.4%。
  → 说明"削烈焰 / buff 非烈焰"都救不了 FR12_A 专属判据，问题不在烈焰自身数值。

## 2. 根因诊断：判据与守卫构成耦合

FR_12 守卫（B3 boss）是**铁壁（ironwall）阵容**，而四系克制环 `flame→ironwall→tide→wind→flame` 中**只有烈焰克制铁壁**。
因此"对铁壁 B3 的胜方含烈焰"在数学上被钉在 ~98–100%——这不是主导策略，是**匹配克制（fire melts iron）**。

为验证是否全局主导，改测**非铁壁守卫**与**全部 12 个真实 FR 守卫**：

| 守卫 | 构成 | 玩家胜率 | 胜方含烈焰 |
|---|---|---|---|
| FR12_A（铁壁 B3） | ironwall×3+tide+wind | 7.4% | **98.4%** |
| TIDE 守卫（自构） | tide×3+iron+wind | 19.3% | 68.3% |
| WIND 守卫（自构） | wind×3+tide+iron | 17.5% | 76.0% |
| FLAME 守卫（自构） | flame×3+tide+iron | 1.3% | 90.6%（玩家大败，wind 克 flame） |

**全部 12 个真实 FR 守卫（data_guards.json）：**

| 守卫 | 构成 | 玩家胜率 | 胜方含烈焰 |
|---|---|---|---|
| FR_01 | — | 100.0% | 77.2% |
| FR_02 | ironwall×3 | 97.4% | 78.2% |
| FR_03 | ironwall×2+wind | 99.9% | 77.3% |
| FR_04 | ironwall×3 | 78.6% | 83.3% |
| FR_05 | ironwall×2+tide | 98.6% | 77.8% |
| FR_06 | ironwall×4+flame | 65.3% | 85.6% |
| FR_07 | ironwall×2+wind | 98.1% | 77.8% |
| FR_08 | ironwall×2+tide | 87.2% | 79.4% |
| FR_09 | ironwall×4+wind | 19.5% | 99.0% |
| FR_10 | ironwall×3 | 97.4% | 78.2% |
| FR_11 | ironwall×2+wind | 94.0% | 77.9% |

> \* FR_12 此处 0.4% 为 2000 舰队采样噪声（低概率事件）；锁链全量口径为 R1-off 11.96% / R1-on 6.73%，仍为权威值。烈焰占比 100% 与全量一致，稳健。

**跨全部 12 守卫聚合：玩家胜率 78.0%，胜方含烈焰 = 79.4%**（全空间基线含烈焰 = 75.8%）。

## 3. 结论

1. **无全局主导策略**：跨真实守卫聚合烈焰占比 79.4% ≈ 基线 75.8%，仅高 3.6pp。
2. **"烈焰必选"是误判**：源于只对铁壁 B3（FR_12）单点测量；铁壁仅被烈焰克制，属正常匹配设计。
3. **三维/四维扫描 0 通过是判据缺陷的表征**，不是平衡缺陷——任何补丁都救不了"对铁壁守卫测烈焰占比≤85%"这条与克制环耦合的死判据。
4. **R1 无需为重平衡服务**：R1 的真实且成立的价值是治愈 UR 卡数值垫底（商业风险），与"破主导"无关。保留 R1 独占机制提案即可。

## 4. 验收判据修订建议（取代原 ≤85% vs FR12_A）

- **退役**子判据"胜方含烈焰 ≤85%（对 FR12_A）"——它测量匹配克制，非主导。
- **改用守卫无关聚合**：`跨全部 FR 守卫聚合的胜方含烈焰占比 ≤ ~82%`，且**任一非铁壁类守卫的烈焰占比 ≤ 基线+10pp**。
- 按此判据，**当前设计已通过**（聚合 79.4%，非铁壁守卫 68~86%）。无需任何 `stat_table_version` 补丁、不触发 `ruleset_hash` 重冻。

## 5. 对冻结 / Phase 3 的影响

- `ruleset_hash` 终表**不受任何影响**，无需为"破烈焰主导"重冻。
- R1 提案状态：从"验证 FAIL / 需整体重平衡"改为"**验收判据误判，实际无主导；R1 维持 UR 商业提案**"。
- 开放平衡项（原"烈焰主导策略"）关闭，替换为"验收判据待重定义（守卫无关聚合）"。
