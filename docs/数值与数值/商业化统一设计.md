# 大航海 SLG · 商业化统一设计（主商业化：船员 Gacha）

> 文档类型：商业化 / 付费系统总设计  
> 版本：**v1.1**（2026-07-29 对齐口径冻结表）  
> 对齐：`00-口径冻结表_SSOT.md` · `数据层/constants.md` · 主文档第十二章 · 经济模型 v0.3  
> 核心结论：**以「船员（角色）gacha 卡池」承担主商业化；资源 / 皮肤 / 体力补充均为辅助。**

---

## 0. 设计定位与反转说明

此前《玩法设计圣经》曾将「付费补体力」暂列为主付费点。**该假设已作废**：

- **主商业化 = 船员 gacha**（获取战斗属性角色 + 命座机制深度）。
- **辅助商业化 = 体力补充 / 资源礼包 / 皮肤外观 / 通行证月卡**。

> 经济模型 v0.3：gacha = `$TIDE`/航海晶第一销毁 sink（`D_GACHA_TARGET≈3000/天`）；体力补充为辅助（`D_STAMINA_TARGET≈700/天`）。

## 1. 货币与代币流

```
法币 ──(onramp)──▶ 航海晶（链上符号 $TIDE）──(兑换)──▶ 招募令/抽卡消耗 ──(gacha)──▶ 船员卡
                        │                                              │
                        └──(免费产出)── 护岛者入账/赛季奖励/活动 ──────┘
```

- **航海晶** = 硬货币（与主文档一致）；文档中写 `$TIDE` 时与之**同指**，禁止另起第三套硬币。
- **琥珀币** = 软货币（日常/月卡赠，不可直购）。
- **招募令**或直接扣航海晶（160/抽，见 `PULL_COST_CRYSTAL`）均可；汇率细节 playtest，硬约束是单抽 160 晶对账方案 C。

## 2. 卡池系统（概率合规）

### 2.1 稀有度与基础概率（示例值，待合规核定）

| 稀有度 | 定位 | 基础概率 | 战斗属性强度区间（战力值，受 STAT_CAP 再截断） |
|---|---|---|---|
| 海员 R | 过渡 | 78% | 80–120 |
| 精锐 SR | 主力门槛 | 18% | 150–220 |
| 传奇 SSR | 核心战力 | 3.5% | 280–380（展示分；进战属性仍受 `STAT_CAP`） |
| 神话 UR | 顶配/限定 | 0.5% | 450–600（同上） |

> 概率须全量公示。战力展示分 ≠ 可无限堆伤害；进战一律过 `STAT_CAP` + `RESTRAINT`。

### 2.2 保底机制（**冻结 · 对齐主文档 §12.3 / constants**）

| 池 | 小保底 | 大保底 | 备注 |
|---|---|---|---|
| **角色常驻 / 赛季 UP** | **70**（50/50 UP） | **140** | `PITY_SOFT` / `PITY_HARD` |
| **舰装 / 武器池** | **60** | **120** | 定轨：连续 2 次未出目标 → 第 3 次必出 |
| 十连 | — | — | 每十连必出 ≥1 SR |
| 新手启航 | — | — | 建号前 30 天：第 20 抽必出 SSR（转化留存） |

> **作废**：硬保底 120、限定硬保底 60、软保底 90 必出 SSR 等旧示例。若合规要求微调，先改 `constants.md` 与口径冻结表，再改本文。

### 2.3 卡池类型

| 卡池 | 周期 | 内容 | 定位 |
|---|---|---|---|
| 远洋招募（常驻） | 常开 | 非限定角色 | 稳态付费入口 |
| 赛季主题 UP（限定） | 每赛季 1–2 期 | 当期体系核心 UR/SSR | 收入高峰；满命锚定方案 C |
| 启航招募（新手） | 建号前 30 天 | 低价 + 20 抽保底 SSR | 转化留存 |
| 武器/舰装池 | 与 UP 同步 | 当期舰装 + 定轨 | 辅助强度，受 `GEAR_STAT_CAP` |
| 复刻 / 纪念池 | 不定期 | 往期限定返场 | 回流 |

## 3. 船员战斗属性（与四体系绑定）

每位船员卡 = 一个「将」位，携带：

- **体系归属**：烈焰 / 铁壁 / 疾风 / 潮汐。
- **基础属性**：atk / def / spd / hp，养成后受 `STAT_CAP` 截断。
- **技能 / 命座**：C1 起交付机制深度（主文档 §12.3.2）；**不跨体系免疫克制**。

### 3.1 升星 / 命座

- 重复卡 → 碎片 → 升星 / 命座（上限 C6 = `CONSTELLATION_MAX`）。
- 免费路径：POI 掉落船员（`1/480`）+ 活动/赛季招募资源。
- 付费路径：gacha 加速；满命成本锚定 **≈¥15,000（方案 C）**。

### 3.2 与战斗公式对齐

- 克制：`RESTRAINT = 1.3` / `RESTRAINT_DISADV = 1/1.3`（对称环）。
- 结论：**高稀有度 ≠ 必胜**；编队克制与环境仍可反制。

## 4. Gacha 作为主 Sink（数值）

| 参数 | 值 | 说明 |
|---|---|---|
| 单抽 | 160 航海晶 | `PULL_COST_CRYSTAL` |
| 付费渗透假设 | 30% | `PAID_TIER_PENETRATION` |
| **d_gacha（主 sink）** | **≈ 3,000 /天** | `D_GACHA_TARGET` |

> 销毁排序（主→辅）：gacha(3,000) > 质押锁仓(3,000)* > 体力(700) > 资源礼包(450) > 皮肤(350) > 赛季回收(500) > 高级铸造(300)。  
> *质押为移出流通，非真销毁。

## 5. 辅助商业化（明确降级）

| 项目 | 类型 | 战力 | 说明 |
|---|---|---|---|
| 体力补充 | 便利 | 无（仅行动次数） | 档位示例：小 30 / 中 68 / 大 128 航海晶；$TIDE 同指 |
| 资源礼包 | 便利 | 无直接战力 | 时间节省；主线资源仍靠 POI |
| **外观皮肤** | cosmetic | **0 战力** | 立绘 / 特效 / 头像框 |
| **资源向皮肤/岛饰** | 便利 | **0 战力**；资源/仓容 ≤ **+30%** | `RESOURCE_SKIN_CAP_BONUS`；**禁止**进伤害公式 |
| 通行证 / 月卡 | 留存 | 无直接战力 | 给抽卡资源 + 软币 |

> 红线：任何付费项不得绕过 `RESTRAINT` 或突破 `STAT_CAP`。

## 6. 付费平衡护栏

1. **属性来源白名单**：① 船员 ② 升星/命座 ③ 船体/舰装 ④ 环境。皮肤/体力/资源礼包不进战斗属性。  
2. **稀有度 / 命座封顶**：C6 + `STAT_CAP`。  
3. **免费路径可达**：POI `1/480` + 赛季招募资源 → 零氪可参与核心玩法。  
4. **克制反制**：`RESTRAINT=1.3` 保护中低氪。  
5. **税收 ≤5%** + 多 sink，抑制鲸鱼垄断。
