# 卷一 · 总纲与核心循环

## 1.1 设计支柱

| # | 支柱 | 玩法落点 |
|---|---|---|
| P1 | 海洋即主角 | 洋流=自动航线、潮汐=赛季高潮、风暴带=风险溢价 |

## 1.2 核心循环三层次（详设）

### 1.2.1 微观循环（单日）
**时间轴**：登录（0 点体力刷新 120）→ 主界面看洋流今日指向 → 消耗体力行动 → 结算 → 次日。
**行动类型（体力口径：[B1] 已决 — POI 探索 =6、攻岛 =8；下列为全量愿景行动清单，不再"各消耗 1 体力"）**：
- 探索 POI（海怪/遗迹/迷雾裂隙）→ 资源/卡/图纸
- 采集（岸边/种植园）→ 基础/贸易资源
- 贸易航行（港口间）→ 价差收益
- 占岛/防守（PVE 守卫）→ 岛主权
- 科技研发（消耗资源，不耗体力，但需先有资源）
- 联盟事务（税收设定/支援，免费）

**每日钩子（必做感）**：
1. 洋流今日指向的核心 POI（限时高收益）→ 引导主动探索
2. 护岛者岛产/税收被动入账（离线也累积）→ 登录正反馈
3. 联盟任务（协作产出）→ 社交黏性
4. 赛季里程碑进度条（距纪元IV/Boss）→ 长期目标

# 卷四 · 子玩法系统（10 项 · 全量愿景 · 设计可验证 · D3 修订）

> 每项格式：定位 / 入口 / 规则 / 产出 / 联动 / 数值基线（可验证）。  
> **工程说明**：Demo 仅交付 4.1 / 4.2 / 4.5（战斗）/ 护岛者经济闭环；其余为入口桩或 P1/P2。详见 Demo 契约。

### 4.1 探索与 POI
- 定位：海域上的可见机遇，日常资源主来源。
- 入口：地图漂移 POI 图标，洋流今日指向高亮。
- 规则：消耗 6 体力（`STAMINA_COST_POI`，[B1] 已决）；海怪(2–3)/遗迹(1–2)/迷雾裂隙(2) 难度；随机刷新航线半径内。
- 产出：资源（单次 ÷24，见经济模型 §1.1）、NFT（1/480、1/960）。
- 联动：产出喂升级/科技；迷雾裂隙出可上链船员卡。

### 4.2 占岛与护岛者
- 定位：从漂流者到岛主，经济正反馈核心。
- 入口：岛屿外围「失落守卫」PVE；击败→占岛。
- 规则：Tier 决定守卫强度；占岛后成护岛者，可规划产出/税收（≤5%）。
- 产出：岛专精产出（见世界观第4表）、采集税（上限5%）、种植/贸易港。
- 联动：护岛者金库→联盟→经济 P5；核心岛★给全域税收。

### 4.3 贸易与跑商
- 定位：跨港价差套利，经济第二支柱。
- 入口：港口界面「贸易航行」，选目标港。
- 规则：单商品港口价=Base×供需×港修×事件（经济模型 §4）；价差>运费+风险溢价可套利；风险=海盗/风暴/战区。
- 产出：金币/$TIDE 价差收益；贸易税回流护岛者/公司金库。
- 联动：纪元IV 跨海域三角贸易（寒铁→星银→丝绸），星银硬通货。

### 4.4 科技研发
- 定位：三文化差异化成长。
- 入口：科技树界面（按出生文化 + 通用疾风）。
- 规则：T1–T4 递进，资源成本（世界观 §5.1）；高阶需潮汐之核（NFT）。
- 产出：体系增益（护甲/能量/烈焰/贸易等）。
- 联动：战力；跨季继承（D1 留）。

### 4.5 卡牌战斗 / 体系克制
- 定位：战斗核心。
- 入口：PVE 守卫 / 占岛 / Boss / GVG。
- 规则：四体系闭环克制 烈焰→铁壁→疾风→潮汐→烈焰，`RESTRAINT=1.3`（约 +30%；卷五 5.2）；组合技=将(卡)+船体+环境。
- 产出：胜利掉落资源/卡/岛屿权/Boss 奖励。
- 联动：所有对抗玩法共用此战斗内核。

### 4.6 联盟系统
- 定位：协作与组织。
- 入口：联盟界面，结盟/创建。
- 规则：成员上限（科技「氏族议会」+5）；护岛者税收设定；联盟战（GVG）。
- 产出：联盟金库（税收+贸易费分成）、协作 Buff。
- 联动：占岛(4.2)、贸易(4.3)、征战(4.7)。

### 4.7 跨海域征战
- 定位：纪元IV 领土对抗（GVG/PVP）。
- 入口：跨海域通道（纪元IV 暂开）。
- 规则：攻击他海域联盟岛/船；三海域特产互通。
- 产出：占领收益、战功、排名。
- 联动：联盟(4.6)、战斗(4.5)、贸易(4.3)。

### 4.8 世界 Boss / 海皇先驱（D4 更密）
- 定位：高频全服协作，赛季高潮之一。
- 入口：Boss 界面，中型周常 + 纪元IV 大型。

- 克制方对被克制方：**最终伤害 ×1.3**（文案可写「约 +30%」；锚 `数据层/constants.md`）。
- 环境偏好：逆风→铁壁稳、顺风→潮汐充能（见 3.4 主题权重）。
- 组合技：将(卡属性) × 船体基建 × 环境修正 = 实际战力（再过 STAT_CAP / 克制环）。
