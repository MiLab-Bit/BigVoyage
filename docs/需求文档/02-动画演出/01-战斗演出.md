# 02-01 · 战斗演出需求（Godot 2D）

> 上游：战斗设计 · 规格层 · 支柱收口 AC-R4/R5 · 美术圣经 §3.2 / §8  
> 运行时：`client/ui/BattleOverlay` 应消费 `ResolveBattle` 的 `log[]`，禁止另算胜负。

---

## 1. 总时序护栏

| 项 | 值 |
|---|---|
| 单场演出 | ≤25s（Boss ≤40s） |
| 回合体感 | 3–8 round（Boss ≤12） |
| 疾风击间隔 | ~0.3s/段 |
| 铁壁击间隔 | ~0.8s/击 |
| 屏震 | 振幅 ≤4px，≤0.3s；**可关**（可访问性） |
| 慢镜 | combo/UR ≤0.5s；可跳过 |

---

## 2. 四段式镜头（Must）

| 段 | 内容 | Godot 实现提示 |
|---|---|---|
| **开场** | 双舰队自迷雾两侧入场；预测仪表盘闪现 0.5s | `Tween` 位移动画 + UI flash |
| **交战** | 按 log 播放 hit/skill；克制命中高亮 | `BattlePresenter` 队列事件 |
| **拉锯** | 护盾/格挡/控制特写；残血慢推 | 状态挂图标（头顶） |
| **终结** | 屏震 + 终结跳字 + 切战报面板 | `sfx_btl_finisher` 同步 |

---

## 3. 单位与布局（2D）

| 项 | 需求 |
|---|---|
| 站位 | 前/中/后三排（`row`）；左右为攻守双方 |
| 单位表现 | Demo：头像圆框 + 体系脚下光圈▲▣◆● + 血条；P1：半身战姿帧 |
| 血条 | 己方绿`#3FAE7A` / 敌方红`#D84A3A` + 数值；盾条叠层幽蓝 |
| 跳字 | 伤害/治疗/克制+30%；暴击可略放大 |
| 阵亡 | 倒地淡出 0.4s；UR 用特殊 pose（如盾插地） |

**动画资产（P1）**  
每体系通用：`idle` / `attack` / `hit` / `down` 各 4–8 帧（`AnimatedSprite2D`），UR/SSR 可有专属 `skill` 帧。  
P0 Demo 允许「静态立绘 + Tween 冲刺/震动」代替全帧动画。

| ID | 触发 | 规格 | P |

| `vfx_control_silence` | silence | 禁言图标 | P1 |
| `vfx_combo_wall` | 火墙 | 微震+橙银粒子连线 | P0 |
| `vfx_combo_lock` | 锁定爆发 | 青紫锁链光 | P0 |
| `vfx_combo_burnchain` | 焚海连锁 | 三拍：泼油→点线→成海 | P0 |
| `vfx_combo_tsunami` | 海啸 | 潮汐巨浪帧 | P0 |

## 5. BattleLog → 演出映射（工程契约）

| log.t | 演出 |
|---|---|
| `start` | 开场段 |
| `skill` / 主动 strike | 攻击者前冲 + skill VFX + hit |
| `dot` | 跳字 + burn 粒子 |
| `kill` | down 动画 |
| end winner | 终结段 + 战报 |

音频：同帧派发 `sfx_btl_*`（见 03-音效）。  
**确定性**：粒子随机种子 = `hash(seed, event_index)`。

---

## 6. 验收

- [ ] 同 log 播两次，关键事件帧对齐（±1 帧可容）  
- [ ] 克制场次结束页可见「克制贡献」或高亮回看（AC-R5）  
- [ ] 关闭屏震后仍可完成战斗  
- [ ] 单场非 Boss ≤25s
