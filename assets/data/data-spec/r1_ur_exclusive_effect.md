# R1 · UR 独占效果提案（兼解烈焰主导策略）

> **作者**：游承峰（主理人） · **日期**：2026-08-02 · **关联**：`COMPILATION-REPORT.md §8.4` / `10-经济 §6.5 风险 R1` / `11-经济 §6.2`
> **状态**：✅ **已决合入规格（2026-08-06 三刀收口 · 刀 2）**——4 个独占机制为 UR 欲望终稿，见 `玩法与系统/支柱收口-构筑UR克制.md`。原"需单解烈焰主导"目标经诊断**不成立**（见 `r1_dominance_diagnostic.md`）；R1 **不为重平衡服务**，服务 **AC-U1–U4**（情境不可替代）与构筑轴 AC-C2。
> **性质**：机制规格（非数值线性放大）。**设计已决**；工程实装批次须重冻 `ruleset_hash`（破甲/焚尽属战斗常量级）。欲望证成**禁止**再用「纯输出 η ≥ 同体系均值」。

---

## 0. 一句话

UR 卡当前在纯输出效率上是全表最差（祝融之裔 645/cost vs 火药学徒 1,770/cost，差 2.74×）。对一个要卖 NFT 稀缺性的链游，这直接伤害价值叙事。
**解法**：给 4 张 UR 各一种「独占级机制」（不是更大数字），让 UR 溢价来自机制而非线性数值。

> **关于"兼解烈焰主导"**：本提案最初附带"反制烈焰 DoT 主导"的二级目标。但 `r1_dominance_diagnostic.md` 证明**原"烈焰主导"是对铁壁 B3 单点测量的误判**——跨全部 12 真实 FR 守卫聚合烈焰占比 79.4%≈基线 75.8%，**无全局主导策略**。因此 R1 只需服务其**真实的 UR 商业价值**，无需为重平衡背锅；潮汐吸 DoT / 铁壁破甲光环等机制作为 UR 独占特色保留即可。

## 1. 问题诊断

### 1.1 R1 商业风险（为什么必须做）
- `11-经济 §6.2`：flame UR η=1,084 < 同体系均值 1,434；tide UR η=710 < 838。UR 在纯输出上全表垫底。
- `20-叙事 §5` 已警示：叙事把 UR 塑造成传奇，数值却不如两张 R —— 反差伤害 NFT 价值叙事。
- 结论：UR 的溢价**只能来自独占机制**，不能来自 atk/def 线性堆。

### 1.2 烈焰"主导"——经诊断属误判（记录根因，但非全局问题）
- `GDD-03 §6.7(d)` 原实测：对 FR_12（铁壁 B3）胜方含烈焰 **99.9%**（全编队空间基线仅 75.8%）。
- 该读数**误判为全局主导**。`r1_dominance_diagnostic.md` 证明：FR_12 守卫是铁壁阵容，而四系克制环中**只有烈焰克制铁壁** → 对铁壁 B3 的烈焰占比被钉在 ~98–100% 属**正常匹配克制（fire melts iron）**，非主导策略。跨全部 12 真实 FR 守卫聚合，胜方含烈焰 = **79.4% ≈ 基线 75.8%** → **无全局主导**。
- 根因（技术事实，仍成立，但仅影响铁壁类匹配）：
  1. **DoT 绕过护甲**——D13② 后 DoT = `max(1, round(baseAtk×dotRate×restraint − target.def×DEF_COEF))`，但 `DEF_COEF` 仅 0.30，相对直伤仍强；
  2. **DoT 绕过护盾**——`bv_engine.py:106-108` DoT 直接扣 `hp`，而 `:150-151` 护盾只挡直伤 → **没有任何机制能吸收 DoT**；
  3. 全 20 卡里**只有 `FLAME_UR_01 祝融之裔`（0.30 DoT）是强火焰核心**。
- 结论：R1 的 UR 独占机制（含潮汐吸 DoT、铁壁破甲）作为 UR 特色保留；**无需为重平衡服务**，不触发 `ruleset_hash` 重冻。验收判据见 §4（已改为守卫无关聚合）。

## 2. 独占效果设计（4 张 UR，机制非数值）

> 原则：每张 UR 拿一个**别的卡永远没有**的机制钩子；调参数值走 `stat_table_version`（呼应 A-11），机制本身属卡 identity（永冻进 record）。

### 2.1 `TIDE_UR_01 波塞冬·深渊之主` — 独占「渊盾 intercepts DoT」★反制烈焰核心
- 现状：`全队能量盾 baseAtk×0.6`，受 `MAX_SHIELD_MULT=2.0` 上限。
- **独占升级**：该 UR 生成的护盾**优先拦截 DoT**（DoT 每跳先扣盾、溢出再扣血）；盾量放宽至 `baseAtk×1.8`（独占，突破 `MAX_SHIELD_MULT`）；对 DoT 的拦截不受护盾倍率上限约束。
- **反制逻辑**：烈焰 DoT 现被渊盾吸收 → 潮汐核心编队能在 DoT 期内存活，靠控制链/直伤翻盘。**这是把烈焰占比从 99.9% 拉回基线的主机制。**

### 2.2 `IRON_UR_01 霜铁之王` — 独占「破甲光环」
- 现状：`全队 effectiveArmor +25%` + pierce 免疫。
- **独占升级**：额外对**敌方全队**施加 `armor_break`：`effectiveArmor −30%`（等价敌方受直伤提升）。
- **作用**：让非烈焰直伤编队（疾风多段、铁壁反打）对装甲目标的输出恢复竞争力——与"堆火焰 DoT"形成替代路径。
- ⚠ 破甲光环改的是敌方 `def` 全局状态，**属战斗常量级，采纳后须进 `ruleset_hash` 重新冻结**。

### 2.3 `WIND_UR_01 追风之翼` — 独占「真实伤害段」
- 现状：4 段 + 阈值叠加。
- **独占升级**：多段中**至少 1 段为真实伤害**（无视护甲、无视 `DEF_COEF` 减法，等价于 `TRUE_DMG_IGNORES_ARMOR=true` 的那段）。
- **作用**：疾风体系不依赖"堆 DoT"也能打装甲，提供第三类近优策略。

### 2.4 `FLAME_UR_01 祝融之裔` — 独占「焚尽」
- 现状：`全场燃烧 baseAtk×0.30`，无视轻甲减伤。
- **独占升级**：DoT **不可被盾吸收**（焚尽穿透渊盾）+ 盾破后追加 50% 溢出伤害。
- **作用**：保留烈焰强度（商业上 UR 仍强），但**现有了天敌**——渊盾只能吸"普通 DoT"，焚尽穿透它。火焰从"无天敌必选"降级为"强但被特定 UR 克制"。

## 3. 由此生成的克制环（多峰，无单一必选）

```
           渊盾吸收DoT
  潮汐UR ──────────────► 反制 烈焰DoT
     │                      │
     │ 破甲光环         焚尽穿透盾
     ▼                      ▼
  铁壁UR ──► 打高甲       火焰UR（强但有天敌）
     │
     │ 真实伤害段
     ▼
  疾风UR ──► 打高甲（绕过DEF_COEF）
```

- 火焰仍是最强输出之一，但**不再是无条件必选**：遇到渊盾潮汐核 → 被吸收；遇到破甲/真伤核 → 直伤编队并驾齐驱。
- 预期结果：胜方含烈焰占比从 99.9% 回落，出现 ≥2 种近优构筑共存。

## 5. 验证计划（P1 仿真穿刺，采纳前必跑）

1. **扩展 `bv_engine.py`**：加 4 个 UR-exclusive 开关
   - `shield_absorbs_dot`（渊盾拦截 DoT）
   - `armor_break_aura_pct`（破甲光环 −30%）
   - `true_dmg_segment`（真伤段）
   - `dot_ignore_shield`（焚尽穿透盾）
2. **重跑三类度量**（复用 `lock_armor_c.py` 的 sweep 框架）：
   - 全 starting-deck 编队对 FR_12 胜率 + **胜方含烈焰占比**；
   - light/heavy 岛胜率分布；
   - 4 张 UR 的 η 重算。
3. **接受判据** = 第 4 节表格；不达标则调参（盾量/破甲幅度走 `stat_table_version`，不碰冻结常量本身）。
4. ⚠ 新机制 + 调参常量验证后须**重新冻结 `ruleset_hash`**（与现有常量同批，禁止分两次）。
