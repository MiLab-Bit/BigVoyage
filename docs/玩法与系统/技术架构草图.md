# 大航海 SLG · 技术架构草图（Tech & Economy Architecture · 完整版 v1.1）

> 文档版本：**v1.1**（2026-07-29 对齐口径冻结表）  
> **SSOT**：工程首切片以《Demo范围契约》为准；数值以 `constants.md` 为准；冲突裁决见 `00-口径冻结表_SSOT.md`。  
> 研究依据：machinations.io 社区标杆；莉莉丝涌现平衡 / 四阵营克制。  
> 目标：3 人团队、单服 5000 玩家、Aleo 链上确权 + zk 战斗可验证（**Demo 阶段链上全部 mock**）。

---

## 1. 总体架构分层

| 层 | 职责 | 技术取向（3 人可落地） |
|---|---|---|
| 客户端 | 3D 船战背景板 + 卡牌结算 UI + 海域地图 | Unity / 轻量引擎；3D 仅作舞台，降本 |
| 游戏逻辑服务 | 自动航线、体力 POI、占岛、联盟经济、战斗数值 | 中心化服务器（先不做全链，省 gas/性能） |
| 链上层（Aleo） | 资产确权（NFT）、zk 战斗证明、赛季奖励分发 | Leo 程序 + zk 证明 |
| 数据层 | 玩家进度、经济账本（链下数值 + 链上资产映射） | 常规 DB + 链上索引 |

> **关键取舍**：MVP 不把每一步都上链。仅「高价值、需确权、需防作弊」的部分上链（资产 + 战斗证明 + 赛季奖励），其余链下跑以保证 5000 同服流畅。

## 2. Aleo 链上接入设计

### 2.1 资产模型（上链 NFT / 半同质化）

| 资产 | 上链形态 | 铸造时机 | 说明 |
|---|---|---|---|
| 船员卡 | NFT | POI 掉落（限量） | 20 张基础卡 + 变体，可交易 |
| 船 | NFT（状态型） | 船图纸升级时 | 木筏→…→航母，记录升级状态 |
| 岛屿占有权 | 链上记录 | 占岛成功 | 护岛者联盟标记 |
| 星银 / 丝绸 / 潮汐之核 | NFT 或半同质 | 产出/掉落 | 高价值资源可上链 |
| 基础资源（木/麻/寒铁） | 链下数值 | — | 省 gas，仅稀有资源上链 |

### 2.2 zk 战斗验证流程

```
1) 双方提交卡组/阵型「承诺(commitment)」→ 对手不可见（zk 隐私=信息不对称策略维度）
2) 中心化服务器按规则结算战斗（快速、可承载 5000 人）
3) 生成 zk 证明：证明「输入合法 + 结算合规 + 无篡改」
4) 链上验证证明 → 写入战果（占岛/排名/奖励资格）
```
> 价值：防作弊 + 可回放 + 隐藏信息（只有隐私链能做到的差异化，见评委话术）。

### 2.3 Leo 程序职责（伪代码）

```
program sea_battle {
  // 资产注册：船员卡 / 船 / 岛屿
  // commit(battle_input_hash) -> 存储承诺
  // verify(result_proof) -> 校验 zk 证明，更新占岛/排名
  // distribute(season_reward) -> 凭资格证明发放赛季大奖
}
```

### 2.4 资产铸造与掉落（对接第 6 表世界观资源）

- POI 掉落铸造：船员卡 / 船图纸 / 潮汐之核，按世界观「稀有度」列控量铸造（传说级潮汐之核每赛季限量）。
- 护岛者产出铸造：星银（亚特兰蒂斯）、丝绸（中华）作为可上链战略资源，按第 4 表各岛「专精产出」速率上链或半链上。

## 3. 链上经济体系设计（基于 machinations.io 研究）

### 3.1 代币结构：分离「价值代币」与「玩法代币」
> 标杆：Illuvium 将 ILV（治理/价值）与 Fuel（玩法，无限增发）完全分离，玩法消费进金库→回购 ILV 分给质押者，避免玩家为 play 而砸盘。

| 代币 | 角色 | 发行 | 主要 sink |
|---|---|---|---|
| **$TIDE** | 治理 + 价值代币（上限总量 10,000,000） | 赛季奖励 / 质押释放（锁仓） | 治理、高级铸造、交易税计价、质押 |
| 游戏内资源 | 玩法数值（多链下） | POI 掉落 / 护岛者产出 | 升级消耗（燃烧）、交易税、赛季回收 |

### 3.2 经济循环（Machinations 风格：Sources / Sinks / Pools / Lockup）

| 节点 | 类型 | 内容 | 备注 |
|---|---|---|---|
| Source（铸造） | 来源 | 赛季奖励铸造、POI 掉落铸造（限量）、质押释放 | 总量/速率受控 |
| Pool（池） | 池 | 玩家持有 $TIDE、护岛者金库、公司/基金会金库 | — |
| Sink（销毁） | 沉 | 升级燃烧资源、交易税、质押锁仓、赛季部分回收 | **sink 必须 ≥ source 长期** |
| Lockup（锁仓） | 延迟 | 赛季奖励线性/分阶段解锁（参考 Sandbox 6 个月） | 抑制抛压 |

### 3.3 具体参数参考（来自标杆模型）
- **交易费**：参考 Sandbox——NFT 交易收 5%，其中 2.5% 归公司/基金会、2.5% 归创作者（本游戏=护岛者）；
- **质押释放**：参考 Sandbox——质押年化约 20%，但设 6 个月锁仓，避免即质押即抛；
- **玩法消费回流**：参考 Illuvium——玩家游戏内消费（体力补充/高级铸造）进入金库→回购 $TIDE→分润质押者，而非直接通胀增发；
- **红色警报（Machinations「Finding Red Flags」）**：① 通胀≫通缩（source 远大于 sink）；② 无锁仓致即时抛压；③ 价值代币与玩法强耦合（玩家为玩而卖币）；④ 鲸鱼集中；⑤ 缺少可持续 sink。本设计以「分离代币 + 多 sink + 锁仓」逐条规避。

> **可运行模型见配套文档《大航海SLG-经济模型-Machinations.md》与《大航海SLG-经济模型.mach》。**

## 4. 数值平衡方法论（基于研究）

### 4.1 统一底层规则集 → 涌现平衡
> 标杆：莉莉丝《战火勋章》把现实克制（穿甲深度 vs 等效装甲 vs 过穿）提炼为同一套底层规则，所有卡牌在同一规则上设计，避免数值后门与长期崩坏。

本游戏统一规则：
- **伤害类型**：物理 / 能量 / 燃烧(DoT) / 控制；
- **护甲类型**：轻甲 / 重甲 / 能量盾；
- **环境修正**：顺风 +攻速、逆风 +护甲、无风 +能量。
- 20 张卡 + 4 体系全部建于这套规则之上 → 平衡可推导、可涌现。

### 4.2 四体系克制闭环 + 30% 克制加成
> 标杆：《战争之轮》四阵营（水火风土）闭环克制，克制数值加成达 30%，高红度玩家也难「一队穿一盟」，保护中小 R。

```
烈焰强攻 → 克 → 铁壁续航 → 克 → 疾风突袭 → 克 → 潮汐咒术 → 克 → 烈焰强攻
```
- 克制时设 **+30% 伤害/效果** 基准，叠加机制克制（如沉默克蓄力），确保「靠体系不靠爆兵」。

### 4.3 COST / 人员上限限制强力单位
> 标杆：《战火勋章》「部队人员上限」——越强单位可上场数量越少，是传统 COST 的微创新。

- 每艘船有**舱位 COST**，强力船员/将占高 COST → 不能全上最强，强制做取舍与体系搭配。

### 4.4 体系保值 + 赛季环境翻红（反数值膨胀）
> 标杆：SLG 用「赛季地形/环境变化」让旧武将翻红（如赵云 S1 T1→后续 T0），避免强势阵容固化与数值膨胀。

- 每赛季引入**环境权重变化**（如某季「逆风盛行」→ 铁壁翻红），旧体系不淘汰；
- 抽卡/铸造卖的是 **synergy 组件而非纯数值**；同名重复（红度）仅小幅提升，体系搭配才是倍数来源 → 从根本上对抗数值膨胀。

### 4.5 用 Machinations 做模拟验证
- **经济模拟**：以 Sources/Sinks/Pools 建模，跑「玩家恒定」烟雾测试，找通胀拐点（见配套经济模型）；
- **战斗模拟**：把 4 体系属性输入，跑克制胜率分布，识别 T0 固化风险，再回到规则集调参。

## 5. 三人团队分工与赛季路线

| 角色 | MVP 职责 | 扩展职责 |
|---|---|---|
| 后端 / 链上 | 游戏逻辑服务、Aleo Leo 程序、zk 证明接入 | 跨海域、全经济、全 36 岛服务 |
| 客户端 / 战斗 | Unity 3D 舞台 + 卡牌结算 UI + 海域地图 + POI | 完整 3D、特效、全海域美术 |
| 策划 / 数值 / 文案 | 世界观圣经、4 体系数值、经济参数、Machinations 模型 | 赛季内容、平衡运维、全文化科技树 |

**路线（阶段化）**：
- **阶段 A（MVP）**：1 海域 / 6–12 岛 / 20 卡 / 4 体系 / 体力 POI / 最简护岛者经济 / 资产+zk 上链。
- **阶段 B（单海域完整）**：1 海域 12 岛全开 + 该文化完整科技树 + 护岛者经济全功能。
- **阶段 C（三海域）**：全 36 岛 + 三文化科技树 + 跨海域贸易。
- **阶段 D（赛季制）**：跨海域征战 + 世界 Boss + 多赛季叙事弧（见世界观圣经第 11 表）。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 链上性能/费用 | 仅高价值环节上链，其余链下 |
| 经济通胀 | 分离代币 + 多 sink + 锁仓 + Machinations 周期模拟（配套模型） |
| 数值崩坏 | 统一规则集 + 30% 克制 + COST 上限 + 赛季翻红 |
| 3 人产能 | MVP 切片优先，3D 仅作背景板降本，阶段化扩展 |
| 跨海域未做 | 作为演示话术保留，不在 MVP 验收范围 |
| 资源产出与数值对账 | 世界观第 6 表 / 第 4 表 / 经济模型三方对齐，每次改动同步 |
