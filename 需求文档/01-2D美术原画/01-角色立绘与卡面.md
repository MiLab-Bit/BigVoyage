# 01-01 · 角色立绘与卡面需求（Godot）

> 上游：美术圣经 §4 / §9 · 设定集 §2–§5 · `cards.json`  
> 引擎：立绘/卡面进 `TextureRect`/`Sprite2D`；图鉴用高清，编队槽用压缩头像。

---

## 1. 交付矩阵（每卡必交）

| 资产 | 命名 | 源分辨率 | 游戏导出 | 格式 | 优先级 |
|---|---|---|---|---|---|
| 立绘全图 | `char_<ID>_illu` | 2048×2732（3:4） | 1536×2048 | PNG+alpha · PSD 源 | P0（20 卡） |
| 卡面成品 | `ui_card_<ID>` | 2048×2560（4:5） | 1024×1280 | PNG · PSD | P0 |
| 头像 | `char_<ID>_head` | 512×512 | 256×256 | PNG+alpha | P0 |
| 半身裁切（可选） | `char_<ID>_bust` | 从立绘裁 | 512×640 | PNG | P1 |
| 技能图标 | `icon_<ID>_skill` | 256×256 | 128×128 | PNG+alpha | P0 |
| C1 徽标点亮态 | `ui_badge_c1_<ID>` | 128×128 | 64×64 | PNG | P1（有 C1 的卡） |

`<ID>` 必须为 `cards.json` 主键，例：`char_FLAME_R_01_illu`。

## 2. 稀有度立绘规格

| 稀有 | 构图 | 传奇密度 | 张数 |
|---|---|---|---|
| R | **半身** + 1 标志道具 | 生活磨损、可共情 | 8 |
| SR | 半身 + 环境暗示 + 2 道具 | 地域前缀 | 4 |
| SSR | **全身 + 场景** + 尺度反差 | 碑文/传说感 | 4 |
| UR | 全身 + 史诗场景 + 巨型反差；**非人四处理法不可互换** | 神话压迫 | 4 |

**UR 非人法（锁定）**  
- 烈焰 `FLAME_UR_01`：静止背影  
- 铁壁 `IRON_UR_01`：融入城墙（**全池唯一无暖色**）  
- 疾风 `WIND_UR_01`：破碎拖影（禁翅膀）  
- 潮汐 `TIDE_UR_01`：未成形巨物（禁三叉戟/人脸）

## 3. 卡面版式（冻结）

| 区 | 规格 |
|---|---|
| 立绘区 | 画布 90% 安全区 |
| 稀有度框 | 外框 12–16px：R`#9AA3AB` / SR`#5B8DD9` / SSR`#D9A13B` / UR 虹紫金`#B98BFF→#D9A13B`+微光 |
| 体系角标 | 左上 64×64：**形状码▲▣◆● + 主色** |
| 稀有度徽 | 右上 48×48 |
| 卡名区 | 底 16%：羊皮纸`#E8DCC0`+铜边`#C9A227`；显示**真名**（设定集） |
| 属性区 | 右下 atk/def/spd/hp + 技能名图标 |
| C1 徽 | 稀有度徽下方，解锁点亮 |
| 克制角标 | 左下悬停：`克制+30%`暖金 / `被克−30%`红 |

Godot：卡面建议做成 **Control 预制**（底图+动态标签），立绘仅贴 `TextureRect`，勿把文字烤死进 PNG（除展示用营销卡）。

## 6. Godot 导入与使用

| 用途 | 节点 | 说明 |
|---|---|---|
| 图鉴立绘 | `TextureRect` stretch keep aspect | 用 illu 高清 |
| 卡面 | 自定义 `CardView.tscn` | 底框 Theme + 立绘层 + Label 真名 |
| 编队槽 | `TextureRect` 头像 96×96 | `char_*_head` |
| 战斗单位 | `Sprite2D` 或立绘缩略 | Demo 可用头像+体系色脚下光圈 |

`import` 预设：角色立绘开启 **mipmaps**；UI 卡面可关 mipmaps 防糊字。
