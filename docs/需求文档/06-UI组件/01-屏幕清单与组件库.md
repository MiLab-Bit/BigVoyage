## 3. 核心组件规格

### 3.1 预测仪表盘 `PredictDashboard` · **Must / P0**

| 项 | 规格 |
|---|---|
| 位置 | 编队界面常驻（顶或右上） |
| 数据 | 克制 +X% / 被克 −Y%（RESTRAINT=1.3）；combo 提示；可胜/险胜/不可胜 |
| 槽位 | 每槽 ▲▣◆● + 主色 |
| 连线 | 克制暖金 `#FFD27A`；被克红 `#E25B54`；**方向+形状**双通道 |
| 卡面态 | 被克卡红光；悬停明细 |
| SFX | `sfx_ui_predict_ok` / `predict_warn` |
| Godot | 自绘 `Control` `_draw()` 连线 或 `Line2D` in Control |

### 3.2 卡面组件 `CardView`

- 结构：底框 / 立绘 `TextureRect` / 角标 / 真名 `Label` / 属性 / C1 徽  
- 显示名：真名主显示；机制名次要（设定集 §0.6）  
- 信号：`clicked` `drag_started`（编队拖拽）

### 3.3 编队槽 `FleetSlot` ×5

- 空态虚线铜框；满态卡面缩略  
- COST 数字；超限整条红闪 + `sfx_ui_cost_warn`  
- 同体系 >4 软提示（不强制拦截视觉可警告）

### 3.4 资源条 `ResourceBar`

- 体力（120）、战略资源、航海晶图标+数  
- 变动时短脉冲 + 对应 SFX

### 3.5 罗盘 `CompassWidget`

- 复用为：加载、海图指向最近岛、筛选器容器  
- tick 音 `sfx_nav_compass`

### 3.6 羊皮纸面板 `ParchmentPanel`

- 通用弹窗/日志底；铜边 StyleBox  
- 标题区 / 正文滚动 `ScrollContainer` / 底按钮组

### 3.7 战报 `BattleReportView`

- 回合列表；克制行高亮；可展开伤害分解  
- 结束摘要：克制贡献 / COST 利用（支柱收口）

### 3.8 按钮 / 输入

| 组件 | 最小热区 | 备注 |
|---|---|---|
| `VoyageButton` | 44×44 | 主/次/危险三型 |
| `IconButton` | 44×44 | 体系形状必须可读 |
| `Toggle` | — | 屏震/色盲/字幕 |
| `Slider` | — | Music/SFX/VO 分总线 |
| `TabBar` | — | 图鉴四体系 Tab 用形状+色 |

### 3.9 列表 / 其它

- `CardGrid`：图鉴/卡库网格  
- `Toast`：通知，不挡操作  
- `ModalConfirm`：出航/攻岛二次确认  
- `ProgressInvest`：连续投入进度条（养成/开发）  
- `ChainStatusBadge`：已确权 / 结算中 / 未同步（链叙事）

---

## 5. 可访问性（Standard）

- 正文对比度 ≥4.5:1；潮汐紫正文改用亮阶  
- 色盲：形状+纹理+文本；默认增强可开  
- 文本缩放 200% 不破版（容器用最小尺寸）  
- 屏震/闪光可关  
- 焦点：键盘/`ui_accept` 可走主流程（战斗 auto）
