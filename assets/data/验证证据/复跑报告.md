## 4. 口径演进发现（复跑暴露的快照/证据表口径问题）

复跑目的之一是暴露「快照口径 vs 终配口径」的漂移。本次发现 **2 处**，均为**预期差异**（非复现失败），但**建议回写口径注记**：

1. **lock_armor_b B2（FR_06/FR_09）DEF_COEF=0.30 列**：
   - 快照/证据表 #7：FR_09@1.20 Lv10 = **50.0%**、Lv4 = 33.4%（D13② 前，DoT 不扣甲）
   - 终配复跑（当前 bv_engine 含 D13②）：FR_09@1.20 Lv10 = **42.2%**、Lv4 = 24.6%
   - 差异根因：D13②「DoT 过减法扣甲」使 DoT 伤害降低 → 玩家胜率回落。**Q5 决策方向与断崖收窄结论保持成立**（收窄 4.9pp vs 快照 4.3pp）。
   - **建议**：证据表 #7 数值加注「D13② 前口径，终配为 42.2%/24.6%」；RULESET_LOCK §2 仅引用 FR_12 11.96%（D13② 后），不受影响。

2. **bv_curve 0.40 / bv_cascade 任务2 的 FR_09 列**：
   - 快照 out_curve_040b：FR_09 = 4.6/18.4/27.1/44.0（hp_mult=1.35，Q5 前）
   - 终配复跑：FR_09 = 6.7/21.8/31.6/49.2（hp_mult=1.20，guards_hash 冻结值）
   - 差异根因：Q5（FR_09 1.35→1.20）。**当前守卫数据（guards_hash 5b41b7b5…）与终配复跑一致**，快照为 Q5 前旧快照。

> 两处均说明「任何中间快照不得当作现行结论」（证据表口径纪律），终配复跑本身自洽。
