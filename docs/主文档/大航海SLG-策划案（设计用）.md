### 1.1 双对标与差异化切口
本作站在两款品类标杆的肩膀上，但在**空间（陆地→海洋）**、**核心玩法权重（战斗→航海资源）**、**技术叙事（链上可验证）**三个维度切出差异化：

| 维度 | 率土之滨 | 三国志战略版 | 本作（大航海 SLG） |
|---|---|---|---|
| 空间范式 | 陆地州郡争夺 | 陆地州郡争夺 | **海洋海域**（三海域+信风带 / 迷雾 / 航线），空间=出航探索 |
| 核心循环 | 土地连接 + 资源 + 州战 | 武将养成 + 土地 + 赛季剧本 | **航海 + 资源管理主轴**，战斗降为支援原子（第四章） |
| 角色 / 资产 | 武将（养成） | 武将卡（角色化 + 命座） | 四体系指挥官卡（对标阴阳师 + 原神，§8 / §12） |
| 赛季 | 赛季重置 + 霸业 | 赛季剧本（S1/S2 叙事弧） | 赛季剧本接叙事（§9.6 / §10.5 / §11） |
| 战斗定位 | 核心玩法 | 核心玩法 | **短平快支援原子**（auto，确定性纯函数可验证） |
| 技术叙事 | 无 | 无 | **zk 确定性战斗日志 + 角色 NFT**（§3 / §12.4） |

- **继承**：率土的"地域经营 + 长线地缘"骨架、三战的"角色即资产 + 赛季剧本驱动 + 土地连接线价值"（§6.4 / §9.2）。
- **切口**：把品类从"陆地战争"移轴到"海洋 + 沉没世界神话"；把战斗从核心玩法降为支援原子（一切围绕航海 + 资源）；用**反制即协同**四体系克制深度与 **zk 确定性日志**链上叙事，做出两者都没有的体验。

### 1.2 目标用户 persona
**「老周」，32 岁，二线城市 IT 主管**——手游 SLG 七年老玩家，率土 / 三战 / 万国都打过几个赛季；享受"领地经营 + 资源滚雪球"的心流，但厌倦纯数值比拼与无脑氪金碾压；日均在线约 1.5h（通勤 + 睡前），周末集中打州战。动机：在长线世界里留下自己的"秩序印记"（领地 / 联盟 / 剧本贡献）；付费中等（月卡 + 偶尔战令 + 偶抽 UP 池，年付费 ¥2k–8k），要"花得值、不强也能玩"。对区块链 / NFT 半信半疑，但认"资产归属自己"的卖点。

**核心需求清单**：
1. 长线可经营的世界（非一波流，赛季可沉淀，§10.5 不删档）；
2. 策略表达在"决策"而非"手速 / 氪度"（auto 战斗 + 全透明情报，§4）；
3. 公平感（四体系克制环兜底，付费不破体制平衡，§12.5）；
4. 社交归属（联盟 / 州战史诗感，§9）；
5. 资产可沉淀（角色 / 海域永久保留，链上可验证，§12.4）；
6. 叙事沉浸（沉没世界神话母题驱动出航动机，§11）。

### 1.3 口号与「为什么是现在」
- **锁定口号**：「沉没的世界，由你的航线重建秩序」（v0.10 锁定，提案→已定）。
- **为什么是现在**：
  1. **品类窗口**：PC 端策略 / SLG 回暖，而海洋题材 SLG 在国产市场稀缺（率土 / 三战皆为陆地），差异化蓝海；
  2. **链上叙事空白**：zk 确定性日志 + 角色 NFT 在 SLG 长线经济尚无标杆；"资产归属玩家"叙事契合当下用户心智，但本作以克制环+STAT_CAP（付费不破体制平衡）兜住平衡，避开链游"庞氏"雷区（§12.5）；
  3. **技术可行**：auto 战斗 + 确定性纯函数（§4 ResolveBattle）使战斗可上链验证，此前 SLG 难做可验证战斗——时机成熟。

> 与 v0.1 的关键修正：品类从「布阵策略」改为「航海资源管理 SLG」；核心差异点从「编队即编程=唯一策略表达」改为「航海+资源主轴 + 反制即协同战斗深度」。战斗不再是核心玩法本身，而是支撑航海/资源目标的手段。v0.10 进一步补**双对标（率土+三战）差异化切口**与**目标用户 persona**，口号锁定（修 D4）。

## 第二章 核心玩法循环（中央原子 = 航海 + 资源管理）

### 2.1 原子玩法拆解（育碧 RGD / Koster 原子法）
- **中央原子 = 航海 + 资源管理**（持续循环，macro flow 主轴）：
  ```
  侦察海域 → 决策出航(目标岛/路线/编队) → 探索占 POI → 资源回笼 → 调度(生产/养成/贸易) → 再出航
  ```
  这是 SLG 常见心流：长线、低频高爽、资源滚雪球。叙事 Objective「重建秩序」包装每一次出航。
- **战斗原子（嵌套支援，短平快）**：
  ```
  准备(编队:位序双轴+多指令) → 核心机制(确定性 auto 结算, 数秒~数十秒) → 反馈(掉落/占岛/排名) → 代价(败则丢资源/撤退)
  ```
  战斗「好玩」来自：克制高亮演出 + combo 同屏特效 + 短促节奏；atomic parameters（速度序差/克制差/COST差/环境）用 Difficulty Matrix 调爽度，不让战斗拖。

### 2.2 三层循环
- **宏观循环（天）**：登录 → 收资源 → 养成/抽卡 → 编队调整 → 出征争夺 → 赛季推进
- **单局循环（一次出航）**：侦察（全透明敌情）→ 决策出航目标 → 编队（战前，位序双轴+多指令）→ 短平快战斗演出 → 占领/掉落反馈 → 复盘优化
- **长线循环（赛季）**：S1/S2 叙事弧（沉没世界秩序重建）+ meta 进度 + 经济滚雪球

### 2.3 难度 ramp
连续（底端：出航探索易上手）→ 离散（中段：海域争夺与编队博弈难精通）→ 连续（顶端：赛季 meta 长线）。

### 2.4 育碧 RGD Difficulty Matrix（实体表）

> **RGD 方法**：先定义「玩家在每个难度*应该体验到什么*（fun factor）」，再把它**反推成可调参数**——本表就是全案唯一的难度调参入口。每个 atomic parameter 都是一个设计旋钮，对应 `数据层/constants.md` 的硬常量（标 `⚙`）；playtest 时只动旋钮、不破硬约束（接 §7.2.2）。表中难度档与 `islands.json` 的岛 tier 一一对应，并经 §10.5 赛季剧本递进解锁。

**原子参数 ↔ 数据层锚点**
- **速度序差**：`cards.json` `spd`（0–100）+ `WIND_BONUS_SEGMENT = 20`⚙（疾风每超 20 额外 +1 段，上限 `MAX_EXTRA_HIT = 2`）→ 决定先后手与额外段。
- **克制差**：`RESTRAINT = 1.3`⚙ / `RESTRAINT_DISADV = 1/1.3`⚙（克制方 ×1.3；被克 ×1/1.3）→ 四体系互克环（§4.3）。
- **COST 差**：`FLEET_CAPACITY = 10`⚙（COST 上限）+ `COST_BY_RARITY = {R:1, SR:2, SSR:3, UR:4}`⚙ + `FLEET_SLOTS = 5`⚙ + `SAME_SYS_SOFT_CAP = 4`⚙（同体系卡 ≤4/5 槽，强制搭配）。
- **环境修正**：`islands.json` `env_bias.season_mod`（冻洋：ironwall **+15%** / flame **0.95**）+ `windDir`/`tidePhase`。
- **指令匹配度**：§4.5 多指令优先级（战前绑定 fleet，不进战斗输入）。

**Difficulty Matrix 主表**

| 难度档 | 目标体验（fun factor） | 速度序差 | 克制差 (×1.3 / ×0.77) | COST 差 (上限 10) | 环境修正 | 指令匹配度 (§4.5) | 代表岛 (islands.json tier) |
|---|---|---|---|---|---|---|---|
| **教学** | 几乎必赢，学"读敌情 + 排编队" | 玩家 ≥ 敌（先手） | 敌**不克制**玩家主力体系（无 0.77） | 敌 = 玩家（10=10） | 主场（ironwall +15%）敌无修正 | 单指令即可清场 | `light` FR_02–FR_11 (`GUARD_HP_LIGHT = 800`) |
| **常规** | 有来有回，编队微操见长 | 互有先后（±20 段临界） | 偶发单点被克（局部 ×0.77） | 敌 = 玩家 或 小超 +1 | 中性 / 主场边缘 | 双指令组合（如 集火+后撤） | `heavy` 入门 FR_06/FR_09 (`GUARD_HP_HEAVY = 2400`) |
| **挑战** | 需正确体系 + 克制预读 | 敌略快（先手压 +1 段） | 敌主力**克制**玩家（×1.3） | 敌超玩家 +2，但受 `SAME_SYS_SOFT_CAP = 4` 限 | 客场（flame 0.95 不利） | 多指令链 + combo（火墙/锁定爆发） | `heavy` 全开 + 跨体系敌 |
| **Boss** | 极限博弈，全机制验证 | 敌先手 + 满额外段 | 双轴压制（本体克 + 召唤克） | 敌 COST 满 10 且 UR 占比高 | 全场 env 不利 | 全指令 + 体系技链 | `boss` FR_12 (`BOSS_HP = 5000`) |

> **调参纪律**：① 任何难度下 `RESTRAINT=1.3`⚙ 不可改（克制环是核心，gacha/皮肤不可破）；② `STAT_CAP={atk:200,def:200}`⚙ 锁死单卡上限，难度只来自**参数组合**而非数值碾压；③ 难度旋钮的 playtest 校准见 §7.2.2，回归用例见 §4.8（冻洋 FR_06 5 回合清场）。

### 2.5 中央原子「一分钟循环」实例（以 persona 老周登录为例）

> 把 §2.2 的"单局循环"落到一个**真实可玩的第一视角序列**——这是中央原子（航海 + 资源管理）的最小闭环。战斗中无操作，所以**全部 agency 集中在步骤 3–4（读敌情 + 调编队）**，战斗只是演出窗口（接 §4.9）。

| 步 | 操作（老周视角） | 时间 | 策略落点 | 数据层锚点 |
|---|---|---|---|---|
| 1 | **看地图**：开海图，扫迷雾/已探明岛、盟友连线 | 0:00–0:10 | 航海决策 | §6 探索 / §9.2 土地连接线 |
| 2 | **选目标**：挑 `FR_09 冻潮门`（heavy, 2400）——连着自己已占的 FR_05，且 POI=crew+resource（资源调度目标） | 0:10–0:25 | 资源管理 | `islands.json`（tier/poi） |
| 3 | **读敌情**：全透明敌情面板——守军铁壁体系、guard_hp 2400；我方主力铁壁+烈焰火墙 combo | 0:25–0:40 | 策略预读 | §4.2 看得见对方 / §4.3 克制环 |
| 4 | **调编队**（唯一 agency 窗口）：按位序双轴排 5 槽，绑定多指令；校验 COST≤10、同体系≤4；铁壁主场 +15% 占优 | 0:40–0:55 | 编队博弈 | `FLEET_SLOTS=5`/`FLEET_CAPACITY=10`/`SAME_SYS_SOFT_CAP=4`/`env_bias` |

| 6 | **看演出**：确定性 auto 结算（≤25s），克制高亮 + 火墙 combo 同屏特效 | 1:00–1:25 | 体验战斗 | §4.7 确定性 / §4.8 分镜 / §4.9 pacing |

| 8 | **复盘**：看 zk 战报日志，调下次的编队/目标 → 回到步骤 1 | 1:35–1:45 | 长线优化 | §4.6 zk 日志 |

> 设计含义：纯 auto 下，战斗内无 agency；**全部策略表达分布在「航海决策 + 资源管理 + 编队」三层**（见上 §2.5 步骤 3–4）。战斗演出的可读性/爽感是玩家唯一能"体验战斗"的窗口，必须被设计（见第四章）。

## 第四章 战斗设计（短平快支援原子，设计语言）

### 4.1 定位（决策 A：纯 Auto，战斗 = 支援原子）
- 战斗中**无任何玩家操作**。编队完成即 100% 策略表达，战斗是"读盘对不对"的确定性演出。
- 选择理由：最契合"编队是战前准备"；结算保持纯函数 → 确定性/zk 最干净；且把开发资源压在"演出可读性"而非战斗操作。
- 战斗「好玩」三来源：克制高亮、combo 同屏特效、短促节奏（不抢航海/资源主轴戏份）。

### 4.2 结算本质（设计意图，非接口）
- 战斗 = 确定性纯函数 `ResolveBattle(我方舰队, 敌方舰队, 环境)`：同输入同输出 → 可复现/可单测/日志可哈希承诺（zk 反作弊）。`seed` 仅参与演出抖动，不参与胜负。

### 4.3 四体系与克制
- 地理三海域+信风带各绑一体系：冻洋·铁壁（扛）/ 瀚海·烈焰（烧）/ 信风带·疾风（快）/ 渊海·潮汐（控）。（口径冻结表 §2.5；旧称熔海/风海/潮海仅兼容阅读）
- **互克环**：烈焰→铁壁→疾风→潮汐→烈焰；克制方伤害 ×1.3（`RESTRAINT`，文案约 +30%）。
- **反制即协同（核心深度）**：同一对在同队则 combo——火墙（铁壁+烈焰：烧+扛）、锁定爆发（潮汐+疾风：控+打）。玩家怕的体系，正是能组进来的体系。

### 4.4 位序双轴（编队 2D 决策空间）
| 轴 | 作用 | 制造的策略 |
|---|---|---|
| 前/中/后（row） | 受击优先级 + 技能作用域 | 脆皮核心 vs 铁壁墙的摆放 |
| 速度序（speed_order） | 同 round 内激活序 | 高 speed 先手控场打断低 speed 蓄力 |

### 4.5 多指令优先级（战前绑定，非实时）
- 指令列表按优先级升序；冲突取高优先级。类型：集火(focus)/风筝(kite)/保命(survive)/诱 combo(combo_bait)。
- `combo_bait` 进阶：牺牲单卡站位换 combo 触发（呼应反制即协同）。

### 4.6 战斗演出（玩家唯一体验，必须设计）
- **分镜**：开场(双舰队入场)→交战(逐段:预警→释放→命中→跳字)→高潮(combo 特写/慢镜)→结算(胜负+MVP+掉落)。
- **可读性三原则**：① 克制高亮（被克方红光）② 伤害类型色（烈焰橙/铁壁银/疾风青/潮汐紫）③ 可暂停·可回放（研究权）。
- **爽感**：combo 专属 2D 同屏特效；以弱胜强 underdog 特写；「以彼之道」反制闪回。
- **节奏**：疾风(快)演出短促；铁壁(慢)演出厚重——体系性格由节奏外化。

### 4.7 失效边界（设计护栏，锁进数据层）
permastun / 无限 DoT / 盾溢出 / 多段上限 / 单场时长 / 数值上限 / 同体系软上限(≤4)。改动需评审。

### 4.8 实战推演：一场具体的对战（worked example）

> 目的：把 §4.1–§4.7 的抽象机制落到一场可回放的具体对战。数值为**推演量级**（基于 cards.json 真实属性 + §4.3 克制环 + §4.4 位序 + 第七章战力逻辑 + constants 护栏，PLAYTEST_KNOB）；最终精确数值由 `ResolveBattle` 纯函数产出，演出 agent 按日志回放（推演脚本见数据层 `sim_battle.py`）。

#### 4.8.1 场景与情报（决策已定：看得见对方）
- **海域**：冻洋（env_bias：ironwall 受击 +15% 有效护甲）。
- **目标**：FR_06「黑曜岩岛」（tier = heavy，`GUARD_HP_HEAVY=2400`，守军全 ironwall 体系）。
- **玩家可见敌方**：5 张守军卡面 + 体系 + 站位 → 决策"组火焰克制队"。

#### 4.8.5 可读性与「反制即协同」回看
- 全场克制高亮贯穿（山岳守望红光 ×5 round），玩家**看懂为何赢**：不是数值碾压，是"火焰克铁壁 + DoT 绕开物理减伤"。
- **反制即协同微例（PVP）**：若对手换「疾风+潮汐」队，玩家可把火焰队改为**火焰+铁壁同队**——铁壁(扛) + 烈焰(烧) 触发 combo「火墙」（烧+扛），即"你怕的体系正是你能组进来的体系"。这是 demo 最该让玩家在多次对战后自行发现的深度，而非文案灌输。

#### 4.8.6 验证锚点
- 确定性：`ResolveBattle(同输入)=同输出`，本局可哈希承诺（§4.2 / constants `HASH_ALGO`）。
- 护栏未触发：单场 5 round < `GUARD_MAX_ROUND=30`；无 permastun / 盾溢出 / 多段超限。

### 4.9 Pacing 规格（节奏设计，短平快）
战斗是**支援原子**，节奏必须短促、不抢航海/资源主轴戏份（§4.1）。

| 项目 | 常规 PVE/PVP | Boss/海域霸主 | 护栏 |
|---|---|---|---|
| 单场 round 数 | 3–8 | ≤ 12 | `GUARD_MAX_ROUND=30`（超时按剩余 HP 比例判） |
| 演出总时长 | ≤ 25s | ≤ 40s | 超长触发 §4.7 审视 |
| 单击演出 | 疾风 0.3s（快切）/ 铁壁 0.8s（厚重） | 同左 | 体系性格外化 |

**节奏曲线（单场内心流）**：开场(2s 入场) → 交战爆发(R1–R2，集火+combo 首杀，6s) → 中段拉锯(R3–R4，DoT/护盾持续，8s) → 终结(R5，克制高亮收尾+占领，4s)。总 ~20s。

**体系性格外化**：速度序决定演出速度——疾风队整体快切（每秒多击），铁壁队厚重慢镜（每击沉）；同场对战取分轨呈现，让"快/慢"成为体系辨识度（呼应 §4.6 节奏外化）。

**pacing 反模式（禁止）**：① 单场 > 8 round 仍分不出胜负（拖时长）→ 触发护栏或重审数值；② 演出冗长（每击 >1s 且无信息增量）→ 砍分镜；③ 全程无克制高亮 → 可读性失效（§4.6）。

## 第五章 编队与卡牌

### 5.1 卡牌哲学
- **archetype 化**，非稀有度数值梯度。每张卡有角色身份（焚烧者/壁垒/疾袭/潮涌…）、幻想、协同、克制关系。
- **组队即编程**：卡牌技能为被动触发（满足条件自动发动），玩家在编队时决定"哪些触发条件被满足"——你不是在打牌，是搭一台自动打赢的机器。

### 5.2 结构（demo 基线 v0.2，数值待 playtest）
- 20 张样例卡 = 4 体系 × 5 角色；字段见数据层 cards.json。
- **COST**：10 点 / 5 槽；R1·SR2·SSR3·UR4。
- **协同网**：体系内 chain（软上限 ≤4）+ 跨体系 combo（火墙/锁定爆发）。

### 5.3 预测仪表盘（编队 UI 常驻）
- 全透明敌情下，编队界面实时显示：本队对当前敌情**克制 +X% / 被克 −Y%**；**combo 触发提示**（列出将满足的 synergy）。
- 作用：把"数值对撞"变成**可见、可预测、可学习**的博弈。

### 5.4 「同 COST 选哪张」实例（决策博弈，冻洋铁壁环境）

> 目的：证明在 `FLEET_CAPACITY=10`⚙ / `FLEET_SLOTS=5`⚙ / `COST_BY_RARITY={R:1,SR:2,SSR:3,UR:4}`⚙ / `SAME_SYS_SOFT_CAP=4`⚙ 四约束下，玩家不是在"堆高稀有度"，而是在**同一预算里做体系/角色/环境的取舍**。以下三方队均严格吃满 10 COST，针对**冻洋（铁壁环境：铁壁 +15% / 烈焰 ×0.95，见 §6.4 + islands.json env_bias）**的一支 heavy 守卫（ironwall 型，`GUARD_HP_HEAVY=2400`⚙）推演。

**① 编队 A「本命铁壁·扛反击」**（纯体系 + 吃满环境）
| 槽 | 卡 | id | COST | 角色 |
|---|---|---|---|---|
| 1 | 霜铁之王（UR） | IRON_UR_01 | 4 | 全队铁壁免疫穿透 |
| 2 | 山岳守望（SSR） | IRON_SSR_01 | 3 | 物理减伤反打 |
| 3 | 铁壁督战（SR） | IRON_SR_01 | 2 | 全队加甲 |
| 4 | 铁砧卫（R） | IRON_R_01 | 1 | 自身硬抗 |
| 5 | —（空，预算已尽） | — | 0 | — |

- **合计 10 COST / 4 卡**：恰好用满 `SAME_SYS_SOFT_CAP=4` 同体系上限；全队吃冻洋铁壁 **+15%** 环境加成（防御/护甲技能被放大），无克制关系（守卫本身是 ironwall，互不克）。
- **优势**：极致坦度 + 稳态输出，面对冻洋本地 ironwall 守卫几乎无伤磨血；**不依赖稀有卡爆发**，R/SR 即可成型（老周 §1.2 F2P 友好）。
- **劣势**：若遭遇 flame 型对手（被 `countered_by=flame`，即 −30%）会被破甲；纯单体系，无 combo 触发 → 上限偏低。

**② 编队 B「烈焰破甲·速控」**（克制链 + 吃环境罚）
| 槽 | 卡 | id | COST | 角色 |
|---|---|---|---|---|
| 1 | 赤焰龙女（SSR） | FLAME_SSR_01 | 3 | 范围焚烧清场 |
| 2 | 深渊回响（SR） | TIDE_SR_01 | 2 | 强化控制 |
| 3 | 火药学徒（R） | FLAME_R_01 | 1 | 单体点燃 |
| 4 | 燎帆炮手（R） | FLAME_R_02 | 1 | 溅射引燃 |
| 5 | 海皇低语（SSR） | TIDE_SSR_01 | 3 | 沉默禁技能 |

- **合计 10 COST / 5 卡**（4 烈焰 + 1 潮汐，同体系 ≤4 ✓）：用 **flame→ironwall ×1.3**⚙ 克制反转守卫优势；但 flame 在冻洋 ×0.95 → **净系数 1.235** 仍为正；潮汐「海皇低语」沉默锁住守卫技能，掩护烈焰脆皮站场。
- **优势**：克制链 + 控场，对 ironwall 守卫爆发最高；证明"即使环境压你，克制环仍能翻盘"。
- **劣势**：烈焰天生低 def（`STAT_CAP`⚙ 内），若守卫带反伤/先手会被速杀；依赖「沉默命中」概率，非确定；体系单一无 combo。

**③ 编队 C「火墙·体系协同」**（混编 + 反制即协同，最优上限）
| 槽 | 卡 | id | COST | 角色 |
|---|---|---|---|---|
| 1 | 山岳守望（SSR） | IRON_SSR_01 | 3 | 物理减伤反打 |
| 2 | 铁壁督战（SR） | IRON_SR_01 | 2 | 全队加甲 |
| 3 | 赤焰龙女（SSR） | FLAME_SSR_01 | 3 | 范围焚烧清场 |
| 4 | 火药学徒（R） | FLAME_R_01 | 1 | 单体点燃 |
| 5 | 燎帆炮手（R） | FLAME_R_02 | 1 | 溅射引燃 |

- **合计 10 COST / 5 卡**（2 铁壁 + 3 烈焰）：铁壁吃冻洋 +15% 当坦克，烈焰走 ×1.3 克制破甲，且 **flame+ironwall 相邻触发「火墙」combo**（接第四章 反制即协同：火墙=flame+ironwall / 锁定爆发=wind+tide）→ 既坦又爆，且 combo 给额外体系收益。
- **优势**：设计意图的"最优解"——同时吃环境、走克制、触发协同；上限最高。
- **代价**：要求**同时拥有两体系核心卡**（收藏深度），且需理解 combo 触发位置（编队时排相邻）；对纯新手/单体系玩家门槛更高 —— 这正是养成/收集驱动的留量设计。

**三方决策小结（玩家视角，接入 §5.3 仪表盘）**：
| 维度 | A 本命铁壁 | B 烈焰速控 | C 火墙协同 |
|---|---|---|---|
| 吃冻洋 env | +15%（全吃） | flame×0.95 | +15%（仅铁壁部分） |
| 克制守卫 | 无（同体系） | ×1.3→净 1.235 | ×1.3 |
| combo | 无 | 无 | 火墙 ✓ |
| 成型成本 | R/SR 友好 | 需 1 SSR 烈焰 + 控 | 需双体系 SSR |
| 上限 / 风险 | 低 / 低 | 高 / 高 | 最高 / 中 |

→ 同一 10 COST 预算下，三套思路**没有"数值最优唯一解"**，只有效力/成本/风险/收藏深度的不同权衡：这正是「编队即编程」+「反制即协同」在卡牌层的落点，也是 §2.5 老周「调编队」步骤的策略来源。

> 数据层对应：`cards.json` 20 卡 `synergy` 字段均为**卡特定**引用（如 `FLAME_R_02`→`FLAME_SSR_01`「焚海前置」、IRON 链「盾墙→山岳→不破→要塞」递进），非笼统体系描述；combo 矩阵见《协同网矩阵.md》。`countered_by` 字段已按克制环 `flame→ironwall→wind→tide→flame` 校订（D1 已清）。

## 第六章 探索与航海（核心玩法 · 中央原子）

> 立论：本作**一切围绕航海展开，战斗是嵌套的短平快支援原子**（见第四章）。第六章是玩家约 80% 在线时间的载体，是 macro flow 主轴，也是"沉没世界后大航海秩序重建"叙事母题的落地处。设计遵循育碧 RGD：**一个深机制（航线风险回报）扛全章，不堆一次性内容**。

### 6.0 设计意图（设）
- **中央原子**：导航 = 持续心流（连续）；战斗 = 离散零食原子（见 §6.6）。玩家登录后第一直觉是"看海图、想航线"，不是"想打谁"。
- **幻想主轴落地**：探索 = 在沉没后的未知海域中 **reclaim 旧世界秩序**——每揭一片迷雾 = 找回一段失落的文明碎片。
- **RGD 原子参数（atomic parameters）**：航线风险 R / 守军 tier / 环境修正 / 编队匹配度 / 迷雾未知度。五项定义探索难度，Difficulty Matrix 见 §6.8。
- **少即是多**：不靠堆岛屿数量制造深度，靠"同一片海，不同风险回报选择"制造 replay 深度。

### 6.1 海图与迷雾（信息不对称的决策）
- **大地图**：冻洋（铁壁）· 瀚海（烈焰）· 渊海（潮汐）· 信风带（疾风航路）；三海域各 12 岛，信风带为跨海航路。每区绑体系 + 环境修正（出战前已知，编队需适配，见 §4 / §5）。
- **迷雾双层（已定保留）**：
  - **战略迷雾**：未探索海域/岛屿不可见内容（POI / 守军 tier / 事件倾向均未知）→ 制造**发现感与决策风险**。
  - **战术透明**：一旦接战，敌方舰队全透明（见 §4 / §5 情报全透明）→ 让战斗策略可计算。
  - 两层正交：迷雾管"去不去"，透明管"去了怎么打"。
- **迷雾揭开 = 三重回报**：① 地图信息（POI / 守军显形）② **叙事碎片掉落**（失落文明线进度）③ **体系解锁线索**（精通该海前置）。→ "探索即养成"闭环（呼应第八章）。

### 6.2 出航决策（离散决策点 · 风险回报量化）
出航 = **三维耦合**的离散决策：**目标岛 × 航线 × 编队**，互相约束：
- **目标岛**：POI 稀有度（tier）定潜在收益，守军 tier 定风险。
- **航线**：同一目标多条航线，风险收益不同（见下表）。
- **编队**：出战编队决定能应对的风险类型（铁壁环境需铁壁体系适配，见 §4 环境修正）。

**航线风险回报模型（demo 冻洋 12 岛实测锚点，见数据层 islands.json）**：
| 航线类型 | 风险 R | 收益特征 | 随机事件触发 |
|---|---|---|---|
| 顺流近岸线 | 低（R=1） | 沿己方岛链，安全；POI 标准 yield | 5% |
| 截直外海线 | 中（R=2） | 省 1–2 航程；POI ×1.2 | 25% |
| 风暴/迷雾远海线 | 高（R=3） | 直达稀有 POI；yield ×1.8、UR 偏向 | 50% 危险事件 + 守军 tier+1 |

> 示例：FR_12「渊眼」(boss 岛，UR 概率提升，守军 5000hp) 仅能从迷雾远海线高 R 抵达 → 高收益伴随高守军/高事件危险度。这正是"风险回报可读、可预测、可学"（呼应 §5.3 预测仪表盘哲学）。

### 6.3 航行事件系统（原子玩法 · atomic gameplay）
每个事件是一个**游戏原子**：触发 → 位置感 → 核心机制挑战 → 反馈（资源/风险/叙事）。事件把"连续航行"切成有决策张力的离散点：

| 事件 | 类型 | 玩家选择 | 核心机制 | 反馈 |
|---|---|---|---|---|
| 遇难商船 | 道德抉择 | 救援 / 掠夺 | 无战斗，即时结算 | 救援 +声望 +叙事碎片；掠夺 +资源但引敌/−声望 |
| 海怪 | 短平快战斗 | 绕行 / 迎战 | 触发战斗 atom（守军级） | 迎战 ship_blueprint 掉落概率↑ |
| 遗迹 | 纯发现 | 进入 / 跳过 | 无战斗 | 叙事碎片 + 体系解锁线索 |
| 敌对指挥官伏击 | PVP 预兆 | 撤退 / 接战 | 触发战斗 atom | 败则丢部分货舱资源 |
| 贸易风口 | 环境增益 | 利用 / 无视 | 即时 | 该岛 POI 产出临时 ×1.5 |

- **事件与体系耦合**：各海域事件偏向绑定体系挑战（冻洋海怪偏铁壁守军；渊海伏击偏潮汐控场）。
- **原子法"失败有代价"**：任何事件退缩/失败都有明确代价（资源 / 声望 / 船体损伤），不让探索"无脑安全"。

### 6.4 岛屿占领与开发（POI 价值 · 率土土地价值模型）
- **岛屿分级**（demo 冻洋）：start(1) · light(8) · heavy(2) · boss(1)。tier 定 POI 稀有度与守军强度（FR_06/09 heavy=2400hp，FR_12 boss=5000hp）。
- **占领 = 触发短平快战斗 atom**（打守军）→ 占领后解锁**开发**。
- **开发 = 建造链**：泊位(容量) → 船坞(造舰) → 神殿(体系技权重，呼应 §8 养成)。产出进**单资源池**（见第七章 / 资源层）。
- **港口连接线（率土土地价值移植）**：高级 POI 开发需与**己方已占岛相邻**（网格相邻，见 islands.json x/y）。孤岛无法直接深度开发 → 制造"先占边再扩心"的领土逻辑。
- **海域霸权**：连续占岛形成"领地"，领地内产出 +15%（env_bias 叠加）；但领地边缘岛暴露给地缘竞争（第九章联盟战）。

### 6.5 资源管理张力（core loop 真正载体 · 资源管理类玩法）
探索的深度不在战斗，在于**有限约束下最大化探索效率**：
- **体力 STAMINA（STAMINA_MAX=120，regen 1/min）**：每次 POI 探索 / 战斗消耗体力 → 每日探索量被体力 gate（D_STAMINA_TARGET≈700 为 playtest 校准目标，见数据层 constants.md）。
- **货舱容量（cargo）**：单次出航能 haul 的资源有上限 → **push on（高风险高回报）vs 回港补给（安全）** 的核心张力。
- **补给（supply）**：长航线 drain 补给；补给耗尽 → 事件惩罚 / 航速↓。
- **多岛物流**：己方多岛间资源需调度（远程岛建物流链才高效）→ 策略层决策。
- **季节/环境修正**：冻洋 ironwall env_bias（ironwall 1.15 / flame 0.95，见数据层）让"何时去哪片海"成为节奏决策（见 §6.8）。

### 6.6 探索 × 战斗的耦合（中央原子 ↔ 支援原子）
- **战斗触发条件**：守军占领 / 海怪事件 / 伏击事件 → 自动进入短平快战斗 atom（≤30s 演出，见 §4.6 / §4.7）。
- **战斗反馈回流探索**：胜 → 掉落 POI 资源 / 占领；负 → 丢部分货舱资源 + 船体损伤（需回港修）→ 影响后续航程规划。
- **定位清晰**：战斗是探索的" punctuation "，不是主体。玩家记忆点是"那条高风险航线值不值"，不是"那场战斗爽不爽"。

### 6.7 难度曲线 / Difficulty Matrix（落实 RGD）
横轴 = 原子参数，纵轴 = 难度档，标注调参方向（数据层可校准）：

## 第七章 经济与数值框架

### 7.1 经济模型（已定，A 级）
- Machinations 化资源池 + POI 产出 + 掉落率锚定（见数据层，已修正旧值）。

### 7.2 数值框架（已定骨架，常量待 calibrate）

> 定位：数值框架是**数据层 ↔ 玩法**的单一真源落点。战力公式给"养成可见成长 + 匹配"，**不直接喂给 ResolveBattle**（战斗结算见第四章确定性纯函数）。所有权重/曲线参数为 `PLAYTEST_KNOB`，最终锚定 constants.md。

#### 7.2.1 战力公式（Power Formula）
**单卡战力**（用于编队排序 / 联赛匹配 / 养成反馈）：
```
Power_card = w_atk·atk + w_def·def + w_spd·spd + w_hp·hp + SkillScore
```
- 权重（demo 基线，待 playtest 校准）：`w_atk=1.0 / w_def=0.8 / w_spd=0.5 / w_hp=0.25`。
- `SkillScore`：技能价值校准表（按 skill.type 与 rarity 标定，PLAYTEST_KNOB）——dot/multi 偏攻、armor/shield 偏防、control/buff 偏功能，数值从 cards.json 实际技能描述反推。

**舰队战力**（奖励好构筑，但匹配 = 另乘克制系数）：
```
Power_fleet = Σ Power_card + ComboBonus(火墙/锁定爆发) + ChainBonus(同体系≤4)
```
- 克制环在**战斗时**另算（RESTRAINT=1.3，见第四章 / constants.md），不进 Power_fleet → 保证"战力高 ≠ 必赢"，维持 matchup 深度。

**实例（冻洋铁壁环境 demo 队，COST=10 满预算，数值取自 cards.json）**：
| 卡 | 体系 | cost | 基础项合计 = atk+0.8·def+0.5·spd+0.25·hp |
|---|---|---|---|
| 霜铁之王 IRON_UR_01 | 铁壁 | 4 | 591 |
| 铁壁督战 IRON_SR_01 | 铁壁 | 2 | 256 |
| 烈焰船匠 FLAME_SR_01 | 烈焰 | 2 | 214.5 |
| 潮歌祭司 TIDE_R_01 | 潮汐 | 1 | 140.5 |
| 信风斥候 WIND_R_01 | 疾风 | 1 | 141.2 |
| **合计** | — | **10** | **1343.2**（≈134.3/cost） |

→ 该队 base 134.3/cost。同预算 mono-烈焰 UR 队战力不同，但遇铁壁环境被 env_bias 压制 + 克制环反制 → 体现"编队是权衡不是堆数值"。

#### 7.2.2 养成曲线（收益递减 + 突破门槛 + 数值上限）
**等级→属性**（单卡，基础值 = cards.json L1）：
```
stat(L, asc) = min( STAT_CAP[stat],  stat_base × (1 + 0.02·(L−1)) × (1 + 0.08·asc) )
```
- 等级上限由**突破(ascension)门控**（对标原神 20/40/50/60/70/80）：0 突破 = 20 级，每突破 +10 级上限，6 突破 = 80 级 → 养成进度被突破材料 gate，防速成。
- **收益递减**：每级 +2% 为线性基底，但**养成材料成本随等级递增** → 边际属性/单位成本递减（diminishing returns）。
- **关键机制（养成不淹没克制）**：高稀有卡很快触 `STAT_CAP`（atk:200 / def:200，见 constants.md）→ 后续养成的 payoff 转向 **体系技权重强化（机制）+ 未触顶属性**，而非无视克制地堆数值。例：祝融之裔 atk base 160，L20 即 160×1.38 = 221 > cap 200 → atk 固化 200；突破价值 = 体系技「大焚」权重↑（机制）+ def/hp 边际。这与第八章"突破强化体系技权重"、第十二章 A 决策「付费买机制深度与养成效率，数值受 STAT_CAP+克制环约束」完全自洽。
- **命座（gacha dupe，见第十二章）**：给机制不堆数值——C1 解锁专属 combo 触发权，C2–C6 机制/小幅数值，**禁止跨体系免疫**。

#### 7.2.3 平衡方法论（"同 COST 真实权衡"判据）
- **核心判据**：同一 COST 内不存在严格 dominate 卡——每张卡在某些 matchup 被克、某些 matchup 占优（靠 archetype 分工 + 克制环）。
- **playtest 闭环**：
  1. **确定性回归**（D3）：ResolveBattle 同输入跑 100 次输出一致。
  2. **对战矩阵**：每体系 pair 互打，记录胜率 / 回合数 / 剩余 hp 分布。
  3. **调平规则**：同 COST 内某卡 vs 全部同 COST 对手胜率 >60% → 削；<35% → 加强。
  4. **克制环校验**：顺环克制方基线胜率应 ≈ RESTRAINT=1.3 对应区间（验证"反制即协同"成立）。
  5. **COST 预算校验**：COST=10 / 5 槽下组合空间需 > 足够多样（组合学下限）。
- **数值护栏**（constants.md，设计锁定）：`STAT_CAP={atk:200, def:200}` 防膨胀碾压；同体系软上限 ≤4 防 mono 队；多段上限 `MAX_EXTRA_HIT=2`；单场 `GUARD_MAX_ROUND=30`。

#### 7.2.4 数值单一真源（待同步 constants.md）
- 公式权重 `w_atk/w_def/w_spd/w_hp`、SkillScore 表、等级/突破参数、STAT_CAP **均已写入 constants.md**（§数值公式：`SKILL_SCORE_WEIGHTS` / `SKILL_SCORE_TABLE` / `BREAKTHROUGH_MAX` / `SYSTEM_SKILL_THRESHOLD_BASE` / `BREAKTHROUGH_THRESHOLD_REDUCE` / `CONSTELLATION_MAX` / `CONSTELLATION_C1_STRONG`；战斗护栏：`STAT_CAP` / `MAX_EXTRA_HIT` / `GUARD_MAX_ROUND`）——**7.2 数据层同步已收口**。

## 第八章 养成系统（对标阴阳师 + 原神，简化创新）

**基准**：角色养成对标 阴阳师（式神升级/觉醒/技能）与 原神（角色等级/突破/命座）。

**简化创新（已定方向）**：
1. **去「技能升级」冗余**：阴阳师式神技能需喂黑蛋升级，繁琐。本作改为**命座即技能解锁**——抽到重复角色直接给机制，不单独养技能。
2. **突破 = 体系强化而非纯数值**：每次突破强化「该角色所属体系的体系技权重」，让养成**反哺编队策略空间**（呼应核心：养成不淹没克制）。
3. **指挥官 θ 等级 = 系统进度**：解锁编队槽/指令位/被动，**F2P 也能成长**，不与角色付费强绑定。
4. **简化材料树**：单资源池（接经济模型）+ 角色专属碎片（仅来自该角色相关海域/活动），避免阴阳师式多资源焦虑。

> 设计原则：养成必须**强化编队策略空间与体系覆盖**，而非单纯数值膨胀；命座效果**禁止跨体系免疫/无视克制**（见第十二章体制平衡）。

### 8.1 三层养成的关系与资源流向
养成由三条**正交**路径构成，分别回答三个不同问题——三者共同界定"可用编队深度"，但都不走纯数值膨胀（受 `STAT_CAP` + §7.2.2 + §4.7 护栏约束）：

| 路径 | 回答的问题 | 来源（资源） | 产出（效果） | 入口 |
|---|---|---|---|---|
| **命座**（gacha 重复） | 这个角色**能做什么机制** | 抽重复角色（§12.3 gacha）/ 场外交易所买 Soulbound NFT（§12.4.3） | 解锁机制 / 专属 combo（C1 即强，§12.3.2） | 付费 / 交易 |
| **突破**（材料） | 它的**体系技有多强（权重）** | 单资源池（经济）+ 角色专属碎片（该角色海域/活动，§10.4） | 强化体系技权重（触发阈值↓ / 系数↑） | 养成材料 |
| **指挥官等级 θ** | 你能**上多少编队容量** | 出航 / 任务经验（F2P 自然成长） | 解锁编队槽(≤5) / 指令位 / 被动 / 出航次数 | F2P 成长 |

资源流向（养成如何汇入核心原子）：
```
抽卡 / 交易所      ──► 命座(机制解锁)          [付费 / 交易入口]
单资源池 + 专属碎片 ──► 突破(体系技权重)        [养成材料]
出航 / 任务经验    ──► 指挥官等级(系统进度)      [F2P 成长]
        │
        └─► 三者共同决定「可用编队深度」──► 进入第六章出航决策(目标/路线/编队)
```
> 关键区分：**命座给"可能性"（机制），突破给"强度权重"（体系技），指挥官等级给"容量"（槽位）**。纯 F2P 玩家靠指挥官等级 + 突破（材料可肝）也能组出体系内 chain；付费玩家靠命座更快拿到机制型角色——但任何路径都不跨体系、不无视克制（§12.5 红线）。

### 8.2 机制示例 A：突破反哺「铁壁体系技」（战斗内可见）
以 **霜铁之王 IRON_UR_01**（cards.json：skill=fortress / 曾用名霜铁之王，全队 effectiveArmor +25% + pierce 免疫）为例，其**体系技「要塞立场」**在铁壁卡 ≥3 时于第 N 回合展开：

| 突破等级 | 触发阈值（回合） | 体系技表现 | 策略含义 |
|---|---|---|---|
| 突破 +0 | 第 3 回合 | 全队 +25% 甲 + pierce 免疫，持续至战斗结束 | 需"先扛 3 回合再硬" |
| 突破 +1 | 第 2 回合 | 同上，提前 1 回合展开 | 更早成型，对抗疾风多段更稳（铁壁克疾风） |
| 突破 +3 | 第 1 回合（开局） | 同上，且持续时间 +1 回合 | "开场即铁壁"，可直接吃 heavy 岛守卫（§6.4 FR_06/FR_09） |

- **养成反哺策略可见**：突破 +1 让"铁壁阵地流"提前 1 回合成型 → 出航决策（§6.2 风险回报 R 表）更敢打高 tier 岛，探索冻洋 heavy 区风险下降。
- **不破克制**：体系技只强化本体系（铁壁），遇到烈焰（克铁壁）仍被 −30% 压制，突破不提供跨体系免疫。

### 8.3 机制示例 B：命座 × 突破 协同（烈焰）
以 **赤焰龙女 FLAME_SSR_01**（cards.json：skill=焚海，范围 DoT baseAtk×0.25）为例：
- **命座 C1**（§12.3.2 结构）：解锁专属 combo「焚海连锁」（烈焰+烈焰同队时 DoT 叠加更快清场）——给"可能性"。
- **突破 +2**：焚海每回合 DoT 系数 +0.05（机制增强，非 atk 数值堆砌）——给"权重"。
- 二者叠加：C1 已能触发连锁，突破再加速燃烧滚雪球 → 体现"命座给机制、突破给体系技权重"的正交分工。

### 8.4 养成 × 核心原子的闭环
养成不是孤立数值，它直接改变第六章出航决策与第九章地缘博弈：
1. **突破铁壁** → 更早展开立场 → 冻洋 heavy 岛（FR_06 黑曜岩岛 / FR_09 冻潮门，islands.json）攻打风险↓ → §6.2 R 表向高回报档偏移。
2. **命座拿机制角色**（如 S2 波塞冬 C1 解锁「海啸召唤」，§12.3.2）→ 该体系 combo 入编 → §6.6 探索×战斗耦合的战斗触发更可控。
3. **指挥官等级↑** → 解锁第 5 槽 / 第 2 指令位 → 编队从"4 卡单指令"到"5 卡双指令"（§4.5）→ 策略空间扩张但不增数值。

> 闭环校验：养成每一分投入都落在"机制 / 权重 / 容量"三格，受 §4.7 失效边界与 `STAT_CAP` 锁死 → 永远不淹没克制环（用户 A 决策）。

| **出生州** | FR_01 霜锚港（tier:start, 无守军） | 新手保护，不可被外盟攻击 | 0–3 日 |
| **资源州（外圈）** | FR_02/03/04/05/07/08（tier:light, guard_hp:800） | 基础 POI，前期滚雪球来源 | 3–10 日 |
| **资源州（内圈）** | FR_10/11（tier:light） | 需经 heavy 岛连接线才能稳定开发 | 10–20 日 |
| **核心争夺州** | FR_06 黑曜岩岛、FR_09 冻潮门（tier:heavy, guard_hp:2400） | 高价值 POI（ship/crew_ur），**choke point** | 赛季中 |
| **Boss 州** | FR_12 渊眼（tier:boss, guard_hp:5000） | 海域霸权锚点，UR 掉落提升 | 赛季末 |

**双动脉进攻模型**（基于坐标网格相邻）：通往 FR_12 的两条栈道都需先控制一个 heavy 岛——
- 北路：`FR_01→FR_02→FR_03→FR_06(黑曜岩岛)→…→FR_12`（控黑曜岩岛）
- 东路：`FR_01→FR_04→FR_05→FR_09(冻潮门)→FR_10→FR_11→FR_12`（控冻潮门）

两条路都是**单点 choke point**：谁占住 heavy 岛，谁就掐住半边进 Boss 州的咽喉。这把「个人战力」转化为「地缘控制力」，是率土式博弈的精髓。

### 9.2 土地价值与连接线（继承 §6.4，率土土地价值移植）
- **连接线规则**：高级 POI / 联盟建筑开发需与**己方已占岛网格相邻**（见 §6.4 港口连接线）。孤岛无法直接深度开发 → 维持「**先占边、再扩心**」的领土逻辑。
- **领地半径**：以联盟主城（见 9.3.5）为中心，N 格内己方岛屿享 **+10% POI 产出**（连接红利）；超出半径的飞地仅基础产出（飞地惩罚）。
- **关隘加成**：控制 choke point（FR_06 / FR_09）的联盟，对该岛相邻海域的**过路敌方编队施加 -15% 航行补给效率**（呼应 §6.5 补给张力），把地理优势变成可计算的战术压制。
- **土地等级**：每个己方岛按「相邻己方岛数」累计**领地等级**（1–5 级），等级越高解锁更高阶联盟建筑槽位。

### 9.3 联盟系统（首包核心）
联盟是首包社交骨架。设计目标：**把个人探索的产出，通过联盟变成群体目标**（占岛、科技、赛季）。

#### 9.3.1 联盟创建与规模
- 创建消耗：少量软货币 + 一名 R 级以上角色作为「盟旗」。
- 规模档：小型(≤30) / 中型(≤60) / 大型(≤100)，规模影响可占岛上限与科技槽位（大联盟人多但单岛红利被稀释 → 规模 vs 效率的真实权衡）。

#### 9.3.2 联盟科技树（体系向共享 buff）
科技树分四类，呼应四体系神话母题，联盟成员贡献资源点亮：
| 科技线 | 效果示例 | 与玩法耦合 |
|---|---|---|
| 铁壁线 | 联盟建筑 +防御、守岛 -10% 受击 | 鼓励铁壁体系玩家主导防守 |
| 烈焰线 | 协同攻岛 +5% 火焰伤害 | 鼓励烈焰体系玩家主导进攻 |
| 疾风线 | 航行补给效率 +12% | 大地图机动性 |
| 潮汐线 | 情报刷新速度 +20% | 呼应 §6.1 迷雾情报 |
| 通用航海 | 领地半径 +1、POI +5% | 中性红利 |

> 设计意图：科技树让**体系偏好**在联盟层形成角色分工（攻盟/守盟/机动盟），避免「万金油联盟」，增加 meta 深度。

#### 9.3.3 联盟仓库与资源互助（接经济单资源池）
- 成员可捐入**战略资源**（单一资源池，见第七章 7.1）至联盟仓库，用于点亮科技、紧急补给、赛季建筑。
- 互助规则：**每日可申领 1 次**联盟援产（软货币 + 体力回复），冷却 24h；高贡献成员享更高申领额度 → 贡献正循环。
- 防搬空：仓库提现需盟主/副盟主审批，且单日提现上限锁定（常量 `ALLIANCE_WITHDRAW_CAP = 5000`⚙）。

#### 9.3.4 协同占岛与收益分配
- 多人协同攻击 heavy/boss 岛时，按**贡献度（造成伤害占比 + 连接线提供）**分配 POI 产出与掉落权。
- 首占奖励：首次攻下核心争夺州/Boss 州的联盟，全盟获**赛季积分 + 限定皮肤碎片**（非直抽，不破体制平衡，呼应第十二章 A 决策）。

#### 9.3.5 联盟建筑
- **军团旗**（主城）：领地半径中心，被摧毁则失去该区连接红利。
- **要塞 / 关隘炮台**：建在 choke point（FR_06/FR_09），提供区域防御值（守军依据 §4 战斗公式计算）；可被敌盟攻破 → geo 控制权易主。
- 建筑升级消耗联盟资源 + 成员体力（呼应 §6.5）。

#### 9.3.6 联盟内战与领土保护
- **免战保护**：新建 / 遭受重创的联盟享 24h 免战（新人保护）。
- **内战冷却**：同联盟成员间不可互攻（防内耗吞噬）；退出联盟后原占岛进入 **12h 易主冷却**（防「占完就退」的恶习）。
- **叛盟惩罚**：带岛叛盟者，其飞地立即归还无主态 + 个人贡献清零。

### 9.4 外交：宣战 / 停战 / 中立
- **宣战**：联盟可对另一联盟发起「海域战争」（赛季中限次，冷却 `WAR_CD = 72`⚙ 小时），宣战后双方进入 PVP 结算态（占岛可互夺）。
- **停战**：任一方可提案停战，需对方接受；停战后恢复免战保护。
- **中立协定**：小联盟可与大联盟签中立，互不攻击但也不共享 POI → 给弱势方生存空间（meta 政治）。
- 外交状态全服广播，ui 常驻显示（呼应信息透明度原则）。

### 9.5 PVP 天梯（确定性日志结算）
- 赛季制排名，吃 **§4 确定性战斗日志**做公正结算（同输入同输出 → 反作弊、可复核）。
- 排行维度：战力 / 赛季进度 / **克制胜率**（鼓励理解体系而非堆数值，呼应第十二章 A 决策与第七章 7.2.3 平衡）。
- 天梯奖励：赛季积分 + 限定外观，顶级段位额外获**赛季角色碎片**（非直售，缓和 gacha 焦虑）。

### 9.6 赛季剧本目标（接 S1/S2 叙事 + 第十二章赛季角色）
- 每个赛季有**全局剧本目标**（如 S1「重建沉没灯塔」需全服合力攻下 FR_12），达成解锁叙事章节 + 全员赛季奖励。
- 剧本进度由**联盟贡献聚合**驱动 → 个人探索（第六章）→ 联盟贡献（9.3）→ 赛季叙事（第十一章）形成闭环。
- **赛季核心强力商业化角色**（第十二章 12.3）通过剧本 + gacha 双入口获取，但**强度来自机制（C1 即强），不来自无视克制** → 付费玩家是「剧本加速器」而非「平衡破坏者」。

### 9.7 玩家间轻交互（冷却规则）
| 交互 | 规则 | 冷却 |
|---|---|---|
| 借将 | 每日可借 1 名友方角色（限 SSR 及以下），借入编队不可带出场外 | 24h |
| 情报共享 | 共享己方已探索迷雾区域（呼应 §6.1） | 无冷却，但仅限好友/盟友 |
| 军团邮件 | 联盟内广播，含集结召集 | — |
| 支援补给 | 向盟友岛投递体力/资源 | 单日 3 次 |

### 9.8 RGD 社交难度与节奏
- **原子参数**：联盟规模、科技进度、领土连接度、外交态势。
- **Difficulty Matrix（社交层）**：
  | 难度档 | 表现 | 设计响应 |
  |---|---|---|
  | 教学 | 出生州免战，单人可玩 | 引导建盟/借将 |
  | 常规 | 资源州争夺，中小联盟互搏 | 连接线红利显著 |
  | 挑战 | 核心州 choke point 大战 | 需联盟协同 + 科技线 |
  | 赛季末 | Boss 州全服剧本战 | 跨联盟临时协约 |
- 目标：让** solo 玩家有生存空间（借将/中立），联盟玩家有史诗感（剧本战）**，两端都不空虚。

### 9.9 与场外交易所 / 链上的边界（独立模块）
> 贸易**不在此社交系统内**：贸易 = 场外交易所 + 链上设计（见 9.10），是独立经济/区块链模块，脱离游戏内社交。

### 9.10 场外交易所与链上设计（独立模块）
- **场外交易所**：玩家间资源 / 角色碎片流转的**站外 / 独立平台**（非游戏内社交），接经济单资源池（第七章 7.1）。
- **链上设计**：呼应技术架构 zk/链意图——战斗日志可哈希承诺 → 资产 / 战绩可上链验证、可交易、反作弊（详见第三章技术架构）。
- **与社交边界**：链上资产（角色 NFT、赛季凭证）可在交易所流转，但**游戏内社交行为（借将/联盟）不产生链上资产**，避免把社交变成纯金融博弈。
- 与社交解耦：贸易是**经济 + 区块链**模块，不是「加好友」类社交。

## 第十章 内容与赛季（长线心流载体）

> 定位：内容是维持 macro 循环（§2.2）持续心流的**燃料**，不是核心原子本身——核心原子始终是航海+资源管理（第六章）。内容管线的三项职责：① 给长线循环持续新鲜目标；② 让赛季叙事（第十一章）有可玩落点；③ 与新卡/新海/活动共同维持月活与留存。**红线：内容投放不得破坏四体系克制环完整性、不得突破 STAT_CAP 数值护栏、不得偏离航海主轴（奖励以航海资源/POI 为主）。**

### 10.0 设计意图
- **内容 ≠ 核心玩法**：战斗已是嵌套支援原子（第四章），内容更不是玩法本体。内容的"好玩"来自探索新海/收集新角色/推进剧本的**目标感**，而非抢占航海主轴。
- **与三层循环对齐**：内容分层直接映射 §2.2 三层循环——天级（常驻日常）/ 赛季级（新海剧本）/ 月级（活动）/ 周级（UP 池轮换）。
- **护栏同源**：所有内容护栏与 §12.5 体制平衡红线、§7.2.2 养成曲线、constants.md 数值护栏同源——内容投放的是"机制与体系覆盖"，不是"数值膨胀"。

### 10.1 内容分层模型
| 层 | 周期 | 内容 | 是否随赛季变 |
|---|---|---|---|
| 常驻 | 天级 | 日常出航 / POI 采集 / 资源调度 / 养成 | 否（玩法底座） |
| 赛季 | 赛季级 | 新海 / 赛季核心角色 / 全局剧本目标（§9.6） | 是（赛季制驱动） |
| 活动 | 月级 | 主线剧情活动 + 双周小活动 + 节日 | 是（节奏调味） |
| 限时 | 周级 | UP 池轮换 / 挑战本 | 是（投放入口） |

### 10.2 卡牌内容管线（节拍与护栏）
- **池节奏对齐 §12.3.1**：赛季 UP 池 ~21 天轮换（双周池），武器/舰装池同步。
- **每赛季产出规划**（产能见 §10.6，标 `[[待补: 团队产能]]`）：
  - 1 名**赛季核心 UR**（对应当赛季主导体系，机制型，C1 即强，结构见 §12.3.2）；
  - 4–5 名 **SSR** 分布于四体系（补 archetype 深度 / 新协同钩子）；
  - 6–8 名 **4★** 支撑（含新 R 级填线）。
- **护栏（硬约束）**：
  - 所有新卡**必须归属四体系之一** → 新体系数量 = 0，维护克制环（§4.3）完整，杜绝"第五体系"破坏平衡；
  - 新卡数值受 `STAT_CAP`（constants.md：atk/def ≤200）与养成曲线（§7.2.2）约束 → 投放的是"机制/覆盖"而非数值膨胀；
  - 须过 §7.2.3「同 COST 真实权衡」playtest 闭环，避免新卡无脑上位挤掉老卡。

### 10.3 海域/岛屿内容管线
- **赛季解锁新海**（路线图见 §10.5）。每新增一海 = 一张新地图（参照 islands.json 冻洋结构：出生州 1 / 资源州外圈 / 内圈 / 核心争夺 2 / Boss 州 1，共 12 岛）。
- 新海带**主导体系环境偏置** `env_bias`（锚 islands.json `sea_theme`：冻洋铁壁 +15% / 烈焰 −5%）→ 制造"换海即换打法"的学习曲线（呼应 §6.7 RGD Difficulty Matrix）。
- **Boss 岛**（`tier:"boss"`，`guard_hp = BOSS_HP = 5000`，锚 constants.md）每赛季重置为剧本终局目标（接 §9.6）。

### 10.4 活动节奏模型（月活 / 留存日历）
- **月度主线活动（1/月）**：推进赛季叙事碎片（接 11 章"叙事驱动系统解锁"），奖励 = 新体系角色碎片 / 限定皮肤 / 航海资源 —— 不以纯战斗数值为主。
- **双周小活动（~2/月）**：资源产出加成周 / 养成冲刺周 / 编队挑战本（非 PVP）/ 贸易风口周 —— 轻量保活。
- **赛季剧本事件**：接 §9.6 全局目标，按联盟贡献聚合推进，季末 Boss 州全服战（对应 §9.8 赛季末档）。
- **节日 / 联动（不定期）**：软性，不破坏平衡。
- 活动美术 / 数值 / 文案产能全部标 `[[待补: 团队产能·活动人天]]`。

### 10.5 赛季叙事收口与路线图（S1/S2 已定义，S3+ 模板）
**设计原则**：每赛季 = 一海 + 一主导体系 + 一赛季核心角色 + 一全局剧本目标，且剧本目标**引导玩家精通该主导体系**（如 S1 引导精通铁壁）。

- **S1 冻洋（铁壁主导 · demo 切片）**
  - 主题「沉没灯塔的回响」：玩家自霜锚港（FR_01）出发，沿双动脉——北上黑曜岩岛（FR_06）/ 东进冻潮门（FR_09）——推进，终局全服合力攻渊眼（FR_12，Boss 岛）。
  - 引导精通铁壁：冻洋 `env_bias` 铁壁 +15% → 初期铁壁体系天然强势，玩家在探索中自然构筑铁壁队；**赛季核心角色 = 铁壁 UR「霜铁之王」**（`IRON_UR_01`，结构同 §12.3.2）作赛季招牌。
  - 叙事收口：攻下 FR_12 解锁叙事章节「灯塔重燃」→ 解锁后续海域线索（接 11 章）。
- **S2 渊海（潮汐主导）**
  - 主题「深渊的召唤」：解锁新海渊海，引入潮汐环境偏置与潮汐体系新卡。
  - **赛季核心角色 = 波塞冬·深渊之主**（`TIDE_UR_01`，§12.3.2），C1 解锁 combo「海啸召唤」（潮汐+疾风）。
  - 叙事收口：渊海剧本推进解锁疾风 / 烈焰海域线索，为 S3/S4 铺路。
- **S3 瀚海（烈焰）/ S4 信风带深化（疾风）**：模板同，每赛季补一区+体系+核心角色；四体系循环一遍后进入 **meta 赛季**（混合海域 + 跨体系协同挑战）。

**赛季重置规则（防通胀）**：角色 / 命座 / 已解锁海域**永久保留**（不删档）；赛季积分 / 排行榜 / 赛季限定皮肤重置；软币（琥珀币）不跨赛季累积至破坏经济（受 §7.1 + §12.4.2 通缩约束），硬货币（航海晶）链上通缩（§12.4.2 燃烧 / 回购）天然抗通胀。

### 10.6 内容生产产能模型（标注待补）

### 10.7 内容与商业化对账边界（接 12 章）
- 赛季核心角色既是**内容旗舰**也是**商业化旗舰**（§12.3.1 UP 池 + §12.3.2 命座）：内容侧负责机制设计与叙事包装，商业化侧负责 gacha 投放与满命锚定（≈¥15,000，方案 C）。
- 护栏一致：投放再强也**不跨体系、不无视克制**（§12.5 红线），与 §10.2 护栏同源。

### 11.1.2 收口实例：S1「霜铁的誓约」（完整链路）

> 把上表第一行落成一条**可追踪的玩家路径**，证明"叙事碎片→卡→机制→编队空间"真实闭环，而非文案。

**解锁链（4 级回报）**：
1. **体系卡入池**：`IRON_UR_01` **霜铁之王** 进入当期赛季 UP 池（§12.3.1，70/140 保底；老周抽到 C1 即强，§12.3 改造）——叙事给"为什么现在出这张卡"的叙事理由。
2. **机制解锁**：铁壁「要塞立场」体系技从残篇→完整版；即 §8.2 实例中"霜铁之王突破+1 使触发阈值 3→2 回合"的**前置机制**由叙事交付，养成投入（突破材料）才有意义。
3. **海域进阶**：冻洋 `env_bias.season_mod.ironwall` 由 +15%（开场）进阶到 +25%，制造长线目标且不破 `RESTRAINT=1.3`⚙ 克制环（仍被烈焰 ×(1/1.3) 压制）。
4. **编队空间扩大**：铁壁体系在冻洋的可选编队组合增加（接 §6.7 出航决策 / §8.4 三层养成），老周在 §2.5 一分钟循环的"调编队"步骤获得新选项——**叙事进度直接改变他每局的策略表达**。

**校验（对照 A+ 标准）**：
- 自洽：解锁内容全在四体系框架内，无第五体系 / 无数值碾压（§4.3 / §12.5）。
- 可读：老周能在战报/图鉴看到"霜铁的誓约 100% → 已解锁霜铁之王"（§6.4 发现度图鉴）。
- 不贴皮：解锁的不是皮肤，是改变 §2.5 步骤 4 编队博弈的**实机机制**。

### 11.1.3 护栏：叙事解锁永不越出四体系克制环

> 所有叙事解锁的"强度"都落在 `STAT_CAP={atk:200,def:200}`⚙ 与 `RESTRAINT=1.3`⚙ 内；叙事只能交付**机制/组合可能性**（如 combo 完整版、env_bias 进阶），不能交付"无视克制"的数值（命座禁跨体系免疫，§8 / §12.5）。这保证"叙事驱动系统解锁"与"体制平衡红线"同源同锁，世界观扩张不会破坏战斗核心（§4.3）。

#### 12.3.4 舰装系统（武器池内容物详细设计）

§12.3.1 已引用"武器/舰装池"，但"舰装/神器"本身未设计。本节省清：舰装是**装备层成长**，落在 §8.1 的"机制/权重/容量"三格，与命座/突破/θ 等级正交，**不引入第五体系、不破 §4.3 克制环、受 STAT_CAP + §4.7 失效边界锁死**（用户 A 决策 + §12.5 红线）。

**① 形态与槽位**：每支编队有 1 艘**旗舰**（编队核心，接 §4.4 位序双轴），旗舰开放 **3 个舰装槽 = 武器 / 装甲 / 神器**（`FLAGSHIP_SLOTS = 3`⚙）。非旗舰单位不装舰装——**舰装不进入编队 COST 计算**（`FLEET_CAPACITY` 仅算角色卡，见 §4.5），保持 COST 经济独立。

**② 三类槽的职责（锚 §8.1 三格）**：

| 槽 | 对应格 | 职责 | 实例 | 边界 |
|---|---|---|---|---|
| 武器 | 权重 | 提升某体系技系数 / 触发阈值 | 铁壁「霜铁炮」使「要塞立场」阈值 −1 回合（呼应 §8.2 霜铁之王突破机制，二者叠加但共享阈值下限） | 仅影响所属体系，不生新克制 |

| 神器 | 机制 | 专属 combo 触发权/稳定性 | 「潮汐之锚」使潮汐+疾风 combo 触发更稳 | 呼应 §4.3 反制即协同，不新造克制维度 |

**⑤ NFT 化**：SR+/UR 舰装抽中时铸造 ERC-721（接 §12.4.3 资产化），可于场外交易所交易，与角色 NFT 同机制。

**⑥ 实例（舰装 × 养成正交叠加，仍受锁死）**：铁壁编队旗舰装「霜铁炮(武器) + 玄铁盾(装甲) + 霜誓核心(神器·S1 叙事交付)」——「要塞立场」阈值经霜铁之王突破+1 已 3→2，再叠加霜铁炮 −1，实际达阈值下限（共享下限保护，不开局即满）；装甲槽 +10% def 受 `GEAR_STAT_CAP` 锁；铁壁仍被烈焰 ×(1/1.3) 压制（克制环不可破）。证明舰装是养成/叙事的**补充表达**，不替代核心克制博弈。

### 12.4 链上货币对账（场外交易所 + 区块链经济）

#### 12.4.1 双层货币架构
| 层 | 货币 | 用途 | 流通范围 |
|---|---|---|---|
| **游戏内软货币** | 「琥珀币」（off-chain 或 L2） | 日常消耗：出航燃料/POI 加速/基础养成材料/非 gacha 商店 | 游戏内闭环 |
| **链上硬货币** | 「航海晶」（ERC-20 / 链上 FT） | gacha 抽卡 / 场外交易所交易 / 角色碎片流转 / 赛季特权 / NFT 铸造 | 链上 + 场外交易所 |
| **治理代币（远期）** | 「秩序印」（可选，DAO 阶段） | 社区治理投票 / 联盟决策 / 经济参数调节 | 纯链上 |

> 设计原则：**软货币不可直接购买**（防通胀）；硬货币=唯一法币入口；两者通过「官方兑换汇率」桥接，锁定 **1 航海晶 = ¥0.0956**（方案 C 汇率，法币→晶由充值档位表确定）。

#### 12.4.2 链上货币价值锚定
- **1 航海晶 = 1 抽**（基本单位，对标原神 160 原石 = 1 抽）
- **¥14,979 / 980 抽 ≈ ¥15.3/晶**（方案 C 最坏情况锚定价，对标原神 ¥18,000 C6 的 0.83 倍）
- **场外交易所**：玩家间可交易航海晶（P2P），价格由市场决定（受供需影响：新赛季 UP 角色发布前晶价上涨，季后回落）
- **反通胀机制**：
  - gacha 抽卡**燃烧** 10% 航海晶（永久销毁）→ 持续通缩压力
  - 场外交易所收取 **2.5% 手续费**（其中 1% 燃烧，1.5% 开发者收入）
  - 季度**回购销毁**：用季度收入回购并销毁市面 0.5% 的流通量

#### 12.4.3 角色 NFT 化（链上资产）
- 每个 **UR/SSR 角色** 在抽取时同时铸造为 **NFT（ERC-721）**
- NFT 元数据包含：角色 ID / 命座等级 / 获取时间戳 / 战斗日志哈希（zk 承诺）
- NFT 可在**场外交易所**转让（角色完整带命座进度）
- **Soulbound 设计**：C1 及以上的机制解锁绑定 NFT——即使转手，新主人继承全部命座效果
- 这让「满命 ¥15,000 的角色」成为**真正可交易的数字资产**，而非仅是游戏内数据

#### 12.4.4 体制平衡的链上保障
- 所有命座效果的**规则代码化**进 NFT metadata + 可验证逻辑
- 社区可通过链上数据**审计**任何角色是否违反克制环（如某命座是否含「无视克制」标签）
- 违规角色可被**社区治理投票**禁用/修正（远期 DAO 机制）

#### 12.4.5 软硬币桥接（琥珀币 ↔ 航海晶）

落实 §12.4.1「两者通过官方兑换汇率桥接，锁定 1 航海晶 = ¥0.0956」中"桥接"未定部分。双层货币回顾：琥珀币（软，off-chain/L2，**不可直接购买**）/ 航海晶（硬，ERC-20，法币唯一入口）。

**① 桥接原则（防双通胀）**：
- **单向桥接（软→硬）**：官方提供"琥珀币 → 航海晶"兑换窗口，作为软币**唯一 sink 出口**；反向（硬→软）**永久关闭**——因硬货币是法币入口、软货币不可购买，开反向会同时破坏硬货币稀缺性与软池防通胀（§12.4.1 原则）。
- **比例与上限**（锚 §12.4.2 价值体系）：兑换比例 **150 琥珀币 = 1 航海晶**（`SOFT_TO_HARD_RATE = 150`⚙）；每日兑换上限 **3 航海晶/日**（= 450 琥珀币/日 sink，`SOFT_EXCHANGE_DAILY_CAP = 3`⚙），防止软币囤积一次性冲击硬池；额度每日 0 点自然刷新（冷却 = 自然日）。

**② 反通胀耦合**：经官方兑换产出的航海晶**同样计入** §12.4.2 的 gacha 燃烧 10% 通缩（兑换所得晶抽卡照样燃烧），且兑换总额受"季度回购销毁"同一资金池约束，**不新增链上发行**（净发行≤0 护栏，类比 resources.json `$TIDE net_issuance<=0`）。

**③ 比例依据（150:1）**：锚定玩家日活软币产出——月卡用户日赠 90 琥珀币（§12.2）+ POI/任务约 200–400 → 日活软币 300–500；150:1 使活跃 F2P 约 2–3 日换 1 晶（≈0.006 抽/日），是"极慢硬货币 drip"而非可 farming 通道，符合 §12.5「付费买更宽的路不买更高的墙」——F2P 靠此微量补足缺口而非追赶鲸鱼。

**④ 链上边界**：兑换产出的航海晶与充值晶同质（ERC-20 不可区分），故**无法做"非充值晶免税"**；统一走燃烧 10% 即公平。软币兑换是 L2/off-chain 操作，不产生新链上发行。

**⑤ 实例（persona 老周，F2P + 月卡）**：老周日获 ~300 琥珀币 + 月卡 90 = 390，按 150:1 可换 2 晶（余 90 累积），2 日攒 4 晶，月攒 ~60 晶 ≈ 0.375 抽/月。对老周是"蚊子腿"式补偿；主力硬货币仍来自赛季目标/活动赠晶（§10.4）。结合舰装 F2P 通道（船图纸），**两条非付费线并存**，满足 §1.2「不强也能玩」。

### 12.5 付费不破体制平衡（A 决策，重申与展开）

**一句话**：付费买的是「更宽的路」（角色覆盖、命座机制、效率与便利），不是「更高的墙」（破克制 / 破 STAT_CAP）。

| 维度 | 付费玩家优势 | 非付费玩家路径 | 平衡兜底 |
|---|---|---|---|
| 角色覆盖 | 快速集齐 4 体系 UR | 时间换覆盖（F2P 2-3 周期攒一个 UR） | 克制环：单一体系总有天敌 |
| 机制深度 | C1 即解锁专属 combo | F2P 用基础卡组出体系内 chain | chain ≤4 软上限防碾压 |
| 数值上限 | C6 终极机制 | 编队技巧+克制理解弥补 | 失效边界锁死数值天花板 |
| 容错率 | 高（多体系多 combo 选择） | 低（需精确构筑） | 情报全透明→可计算最优解 |

> **底线红线（写入智能合约层 / Demo 则写入本地护栏）**：
> 1. 任何命座效果不得含「无视体系克制」「免疫某类伤害」「跨体系全额加成」字样。
> 2. 数值加成上限：单命座基础属性增幅 ≤ 20%（C6 累计 ≤ 120%，但受失效边界数值上限约束）。
> 3. 机制解锁不得绕过失效边界（如 permastun 类效果无论几命都触发 §4.7 护栏）。
> 4. 皮肤：外观 0 战力；资源向皮肤仅产出/仓容 ≤ `RESOURCE_SKIN_CAP_BONUS`，不进伤害公式。

7. **遇袭进入战斗** → ≤5s ramp 到全 intensity，克制命中铜管凸显（火焰克铁壁 = lead 盖鼓）
8. **清场回港** → 2s 落 bed，黄金时刻暖大调收尾

→ 音频的 agency 集中在"读敌情听得懂、调编队听得见、出航是主角"，与 §4 全透明 / §2.5 老周需求一致。
