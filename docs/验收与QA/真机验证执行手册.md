## 3. 逐维度协议

### 3.1 M1 核心循环趣味性

- **执行步骤**
  1. 被试无提示开局（S-A 场次），主试记录第一条时间线（《框架》§4.2）。
  2. 完成首次闭环（看地图→选目标→读敌情→调编队→出航→看演出→收菜→复盘）后**静默计时 3 分钟**，观察是否自发发起第二次出航。
  3. 赛后问卷（《框架》§4.6）+ 出声思维摘录。
- **采集数据**：自发二次循环率（≥80% `QA_KNOB`）；单循环时长中位数（1–3 min）；agency 归因（选目标/调编队 ≥70%）；主轴权重感知量表（≥3.5/5）；循环趣味量表（≥4.0/5）；每日钩子可说出数（≥2/4）。
- **通过标准**：6 项指标 ≥5 项达标 = PASS；4 项 = CONCERNS；≤3 项 = FAIL。
- **判 BLOCKER**：无自发二次循环（需主试提示才继续）+ 循环趣味 ≤3.0 → **Blocker**（核心体验不成立）。

### 3.2 M2 心流平衡

- **执行步骤**
  1. 按难度档安排战斗场次：教学（FR_02–05）→ 常规（FR_06/09 入门）→ 挑战（heavy 全开+跨体系）→ Boss（FR_12 渊眼），每档 ≥5 场，记录战报（《框架》§4.4）。
  2. Boss 档对照终配锚点：**FR_12 Lv4 = 11.96%**（D13② 后权威值；~~16.71% / 9.24% / 33.23%~~ 禁止引用，[B3]）。
  3. 观察无聊/焦虑信号（EV-4 行为计数）与主观匹配度（EV-3）。
- **采集数据**：四档胜率；正确/错误体系胜率差；连续全胜/连败场次；首占岛日（≤Day1）；heavy 首胜日（≤Day7）。
- **通过标准**：教学 ≥90% / 常规 55–75% / 挑战差 ≥20pp / Boss 5–15%；主观匹配 ≥3.5/5；首占岛 ≤Day1。
- **判 BLOCKER**：新手在教学档失败 ≥2 次（劝退）；或 Boss 档实测胜率**偏离 [5,15] 区间**（与冻结锚点 11.96% 冲突需溯源——先查数据快照是否一致，再查引擎实现，最后才考虑数值口径问题）。

### 3.3 M3 数值通胀预警

- **执行步骤**
  1. 用真机经济闭环跑 30 步（D1–D30），按《框架》§4.5 经济流水表逐日记账（或导出 CSV）。
  2. 三个玩家档案各跑一组：参考档案 invest_rate=0.80（**权威**）/ 全投入 1.00 / 纯囤积 0.00（仅监控）。
  3. 复算关键锚点：参考档案峰值通胀 **3.34%**（含 refit + ADJ=0.25，终配口径）≤5%。
- **采集数据**：30 日峰值通胀；峰值出现日与当日事件；最大单日投入环比降幅（≤30%）；内容耗尽日（≥Day22 或无）；容量比（≥2.5）；$TIDE 净发行（≤0）。
- **通过标准**：参考档案峰值 ≤5.0% 且无 sink 断崖（任一日总投入环比降幅 ≤30%）。
- **判 BLOCKER**：参考档案峰值 >5.0%（通胀崩）；$TIDE 领取失败（Critical）。

### 3.4 M4 战斗可读性与公平性

- **执行步骤**
  1. 任选 ≥6 场战斗，用《框架》§4.4 日志六要素勾查表逐项核对战斗日志。
  2. 赛后 30 秒内让被试口头归因（EV-2），记录原话与正确性。
  3. 第 3 场后考四体系互克环（烈焰→铁壁→疾风→潮汐→烈焰）识别。
  4. 公平性：无 UR 编队打常规/挑战档记录胜率；皮肤 0 战力核对（EV-7）。
- **采集数据**：日志六要素齐备数（6/6）；胜负归因正确率（≥70%）；克制环识别（≥80%）；可读性量表（≥4.0/5）；无 UR 常规档胜率（≥50%）/ 挑战档（≥35%）；确定性公平感（同输入同输出 → 玩家理解 seed 不影响胜负）。
- **通过标准**：六要素全齐；归因 ≥70%；无 UR 常规 ≥50%。
- **判 BLOCKER**：任何皮肤影响战斗数值 = Blocker；无 UR 常规档 <35%（老周承诺破裂）。

### 3.5 M5 失效边界

- **执行步骤**：逐场战报勾查 7 项护栏触发（《框架》§1 M5 表）——permastun(`MAX_STUN_ROUND=3`) / DoT 无限叠(`MAX_DOT_STACK=5`) / 盾超血(`MAX_SHIELD_MULT=2.0`) / 多段触顶(`MAX_EXTRA_HIT=2`) / 打满 30 回合(`GUARD_MAX_ROUND=30`) / 单卡撞 `STAT_CAP` / 同体系纯堆(`SAME_SYS_SOFT_CAP=4`)。
- **采集数据**：各护栏触发次数（期望 0）；STAT_CAP 撞顶卡清单（重点 `IRON_UR_01` def=170 → Lv7 起不涨，UI 必须有「已达上限」提示）。
- **通过标准**：除「多段触顶 ≤ 偶发」外全部触发次数 = 0。
- **判 BLOCKER**：任一「0 期望」护栏被触发 = FAIL 回炉；STAT_CAP 撞顶无 UI 提示 = Critical 体验 bug。
- **A-12 纪律**：`MAX_STUN_ROUND`/`MAX_SHIELD_MULT`/`TRUE_DMG_*` 若 Demo 未实装，记录表标「本轮不适用」，**不得记为「未触发=通过」**（假阳性证据）。

### 3.6 M6 新手引导

- **执行步骤**：S-A 场次按《框架》§1 M6 六步走（木筏苏醒→顺流靠岛→首次 POI→首占岛→首次贸易/科技→联盟入口），记录每步完成/卡点与出声思维。
- **采集数据**：强制三步完成率（100%）；软引导三步触达率（≥50%）；L3 卡点次数（≤1）；六项心智测验正确率（洋流=航线 / 体力=预算 / 占岛=经济…）；diegetic 教学核对（卡面 `countered_by`/`strong_against` 常驻）。
- **通过标准**：强制三步 100% 完成且无被试卡死；L3 卡点 ≤1 次。
- **判 BLOCKER**：任一强制步骤有被试卡死（引导链断）。

### 3.7 M7 留存信号

- **执行步骤**：每场结束前问「明天上线第一件事是什么」；赛后问卷回访意愿；90 分钟场次内核对 persona 老周六需求命中（日均 1.5h / 中付费 / 花得值不强也能玩）。
- **采集数据**：次日目标清晰度（≥80% 能说出具体行动）；回访意愿量表（≥4.0/5）；长线目标感知（≥60% 能说出一条赛季级目标）；persona 六需求命中（≥4/6）。
- **通过标准**：次日目标 ≥80% 且回访意愿 ≥4.0。
- **判 BLOCKER**：出现「赛季重置删档」（《主案》§10.8 明确反模式）= Blocker。

## 5. 战斗确定性验证协议（D3，同输入同输出 100 次）

- **前置**：G2 引擎已实现 `ResolveBattle` 纯函数（v0.4 全序 `(spd DESC, side ASC, slot ASC)` + 全宽绑定承诺，见 RULESET_LOCK §6 BLK-2/BLK-4）。
- **步骤**
  1. 固定三组用例：教学档（FR_02）/ 常规档（FR_06）/ Boss 档（FR_12_A cost12 hm1.35），每组固定 fleet + env + seed。
  2. 每组同一输入跑 **100 次**，记录每次输出（胜者 A/B、回合数、双方剩余 HP 和）。
  3. 结果归并：若 100 次输出**完全一致** → PASS；若存在任何差异 → 判 FAIL 并开 Blocker 缺陷单。
  4. 另测 3 个不同 seed 同 fleet：胜负应一致，仅「演出抖动」可不同（若引擎无演出层，标注「演出未实装」）。
- **证据**：EV-5（战报日志）+ 自动化断言日志（如 `ResolveBattle` 单测输出）。
- **通过标准**：三组 × 100 次 = 300 次全部同输入同输出。
