## 3. 占位约定（Phase F 统一，2026-08-06）

1. **待回填内容**（需 playtest/数据回填、团队产能等正文占位）→ 一律 `[[待补]]`（可带标签：`[[待补: 团队产能]]`）。
2. **设计裁决状态** → 正文不得散落孤立"待裁决/待定"字样，一律改指《裁决登记册》对应 ID：
   - 已决项（如 **[B4]**）任何位置一律标"已决"；待裁决项（如 **[B6]**）只允许出现在登记册本体或引用其 ID 的正文（如"登记册 [B6]（待裁决）"）。
3. **非登记册覆盖的待决设计项**（11-经济 Q7/O-13、船员设定集 §0.4 C-1~C-5）→ 保留在所属文档跟踪表内，状态列统一标 `⚠待定`，并注明归属（"见所属文档 §X / 非登记册项"）；**不为其虚构登记册 ID**。
4. `🔴待裁决` 仅用于《裁决登记册》本体状态列；其他文档引用待裁决项时用文字 `[B6]（待裁决）` 并链接登记册。
5. 现状统计见 `CHANGELOG.md` v1.2（Phase F）条目。
