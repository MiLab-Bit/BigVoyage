# 05-01 · 舞台级 3D 需求（Godot 4.7 Forward+）

> **范围边界（硬）**  
> - ✅ 海面 / 天空穹顶 / 体积雾 / 简单岛块 / 粒子发射器网格  
> - ❌ 角色人体 3D、舰船高模战斗、绑定骨骼角色（角色走 2D）  
> - 战斗胜负表现仍在 **2D Overlay**；3D 最多作远景底板（可关）

---

## 1. 为何需要 3D

引擎锁定 **Forward+**，用于：  
1. 冻洋海面波光与风暴体积感（美术四原则：尺度/天气）  
2. `WorldEnvironment` 雾与 env_bias 色温  
3. `GPUParticles3D` 雪/浪花（性能优于纯 2D 堆叠时）  
Demo **允许**纯 2D 海图，3D 舞台为 P1 增强。

---

## 2. 资产清单

| ID | 资产 | 面数预算 | 贴图 | P | 备注 |
|---|---|---|---|---|---|
| `mesh_sea_plane` | 海面网格（可 tessellation/shader 顶点浪） | ≤2k tris 平面或 8k 细分 | 法线+泡沫 2K | P1 | `Shader` spatial 海面 |
| `mesh_sky_dome` | 天空穹顶 | ≤500 | 4K HDRI 或渐变 | P1 | `Sky` / panorama |
| `mesh_island_lod` | 远景岛块低模（冻洋 3 种变体） | ≤1.5k/个 | 1K 合并 | P2 | 海图相机俯视时用 |
| `mesh_iceberg_deco` | 冰山/鲸骨装饰 | ≤800 | 1K | P2 | |
| `mesh_fx_emitter` | 粒子发射占位（隐形） | — | — | P1 | 挂 `GPUParticles3D` |
| `mesh_ship_proxy` | **可选**远景船块低模 | ≤500 | 512 | P2 | 仅海图相机；非战斗 |

**格式**：`.glb` / `.gltf`（Godot 原生）或 `.obj`+材质。  
**单位**：1 unit = 1 m；海面置于 y=0。

---

## 3. 材质 / 着色器需求（Godot Shader）

| Shader | 用途 | 关键参数 |
|---|---|---|
| `sea_frozen.gdshader` | 冻洋海面 | 浪高、碎冰密度、反射粗糙、env 色 |
| `sea_abyss.gdshader` | 渊海（P1） | 次表面散射近似、发光带 |
| `fog_volume` | 体积雾 | 密度、高度、色 `#9AA3AB` |
| `env_bias_post` | 全屏冷暖 | color_temp、saturation（可 2D ColorRect 代替） |

灯光：主方向光（永昼冷白）+ 微弱补光；**禁止**无源神性泛光（反例 R-07）。

---

## 5. 场景装配建议

```
World3D (Node3D)                    # 可选，海图增强
├─ Sea (MeshInstance3D + sea shader)
├─ Sky (WorldEnvironment)
├─ Deco (冰山实例化 MultiMesh)
├─ WeatherSnow (GPUParticles3D)
└─ Camera3D                         # 俯视斜 45° 或正俯；可与 2D 海图互斥开关
Battle2D (CanvasLayer)              # 永远在上层
```

性能：PC 开体积雾；移动/Web **关 3D 海面**，回退 2D `env_*_chart_base`。
