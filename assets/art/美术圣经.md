### 2.6 配色使用规则

- **主从比例**：场景/立绘 60% 环境色（含体系 env_bias）: 30% 主体色: 10% 强调色（体系高光 / 语义色）。体系主色必须是画面**主色调**，不是点缀（设定集 §1.5）。
- **穿透三层**：任一体系卡/单位出现时，其体系色同时出现在 ① 单位特效（粒子/描边）② 环境光局部（如烈焰卡开战时甲板暖橙）③ UI 状态（血条/技能图标），三层色相一致。
- **文字对比底线**：正文文字对比度 ≥ 4.5:1，大字/图形 ≥ 3:1（附录 A.2 验收）。注意：潮汐紫 `#7B5FC6` 在墨黑上约 3.8:1，**仅可用于大面积/图形**；小字号文本须用潮汐 02/01 阶（亮紫/浅紫辉光）。

## 3. 构图与镜头语言

### 3.1 构图三原则

1. **尺度反差构图法**（§13.1 原则二）：人物/船队必须与巨型对象同框。参照物从设定集 §1.6 库中选**具体对象**（禁止写「一个很大的东西」）。角色占比规则见 §4.4。
2. **冷暖切分**：单幅画面必须有明确的暖光源（火/灯塔/黄金时刻）与冷环境（风雪/深海/风暴）切分；切分线位置 = 叙事焦点线（参考 `FLAME_SSR_01`「站在冷暖交界线上」）。
3. **景深三层**：前景（人物/道具/残骸）→ 中景（尺度反差对象）→ 背景（环境/天空/雾），三层须有可读的明度差与焦段差（PC 端可用景深）。

### 3.2 镜头语言规范

| 类型 | 规范 |
|---|---|
| 立绘（静态） | 一律取「决定性瞬间」，禁止摆拍感；视线方向留出 1/3 呼吸空间 |
| UR 非人四处理法（**不可互换**） | 烈焰 UR=静止背影；铁壁 UR=融入城墙；疾风 UR=破碎拖影；潮汐 UR=未成形巨物（设定集 §2.5/3.5/4.5/5.5） |

## 8. VFX 与着色器方向（双轨草案 · 引擎依赖段标 `待 G2`）

> 本节「8.1–8.6」为引擎无关方向（全量）；「8.7 / 8.8」为双轨草案（Godot / Unity URP 各一版），**不写代码，只给方向与参数概念**，引擎冻结后收敛为单轨。

### 8.1 VFX 总原则（引擎无关）

- **克制高亮**：克制命中外化 `RESTRAINT=1.3`（确定性纯函数，同输入同输出）。
- **真实材质**：火 = 有烟的真实明火；水 = 物理水；盾 = 半透明能量壳；禁止「魔法特效感」（反例板 R-07）。
- **克制度**：VFX 只服务可读性与叙事，不堆屏幕粒子；单场演出 ≤ 25s（§4.9 pacing 护栏）。

### 8.2 克制高亮（引擎无关规格）

| 项 | 参数概念 |
|---|---|
| 触发 | 克制系攻击命中被克目标 |
| 表现 | 被克方体系色**衰减**（饱和度 −20%、边缘压暗）0.5s；克制方体系色**凸显**（边缘描边爆光 0.5s）|
| 附加 | 目标脚下体系形状码光圈一闪（▲▣◆●）；命中处粒子 = 克制方体系主色 |
| 收尾 | 终结跳字（`克制 +30%` 或伤害数字），战报回看高亮（§7.4 战报面板） |
| 双轨提示 | 参数：edge_width_px、glow_intensity、duration_ms、saturation_drop  |

### 8.3 combo 触发（引擎无关规格）

- 触发：满足 synergy（如「火墙」「锁定爆发」）或 C1 解锁 combo。
- 表现：全屏微震（振幅 ≤ 4px，≤ 0.3s）+ 体系色粒子沿 combo 链连线；UR C1 可加 0.5s 慢镜。
- 记忆点：`FLAME_SSR_01` C1「焚海连锁」必须复现「泼油 → 点线 → 成海」三拍（设定集 §2.4）。

### 8.4 迷雾（引擎无关规格）

- 半透明粒子层 + 深度雾；未探海域高密度（冷灰蓝 `#9AA3AB`），可透出浮岛/塔尖/巨兽剪影。
- 参数：mist_density、mist_color、mist_height、视线衰减曲线、粒子风速。

### 8.5 env_bias 冷暖滤镜（引擎无关规格）

- 按海域定义环境权重：色温偏移、饱和度、对比度、体积光强度、雾色（§5.1 表）。
- 切换 ≤1s 渐变；战斗开场可叠加「双舰队从迷雾两侧入场，冻洋冷蓝环境光」（§4.8.4）。
- 参数：color_temp_k、saturation_pct、contrast_pct、volumetric_light、mist_color。

### 8.6 DoT / 盾 / 控制表现（引擎无关）

| 状态 | 表现 |
|---|---|
| DoT（燃烧/真伤） | 目标脚下体系色火苗 + 每回合跳字；烈焰 DoT = 真实明火（有烟） |
| 能量盾 | 半透明壳 + 受击涟漪；潮汐盾叠加幽蓝辉光 `#3FA9C9` |
| 控制（眩晕/沉默） | 眩晕 = 头顶旋转星纹；沉默 = 口部禁言图标 + 频段封锁线；均叠加形状图标（§2.5） |

### 8.7 双轨草案 A：Godot Shader 方向（⚠ 待 G2）

- **后处理/色彩分级**：优先用内置 `WorldEnvironment`（Environment → Adjustments / Tonemap / Volumetric Fog）承载 env_bias 冷暖滤镜；雾用 `Environment.fog` + 深度雾参数，不写自定义 shader。
- **克制高亮描边**：方向 = 屏幕空间边缘检测后处理（CanvasLayer + full-screen rect），或角色 `SpatialMaterial`/`CanvasItem` shader 内做 `fresnel`/边缘光；参数同 8.2。
- **粒子**：Godot 4 `GPUParticles2D/3D`（材质带体系色），DoT/盾/控制提示符用 `CanvasItem` shader 叠形状图标。
- **性能**：PC 端注重视口分辨率；移动降配关闭体积光、降粒子数（待 G2 冻结）。

### 8.8 双轨草案 B：Unity URP 方向（⚠ 待 G2）

- **后处理/色彩分级**：URP Volume 组件（Color Adjustments / White Balance / Tonemapping）+ 自定义 Full Screen Pass Renderer Feature 承载 env_bias；雾用 `URP Fog` / 深度雾。
- **克制高亮描边**：方向 = 屏幕空间描边 Renderer Feature（后处理）或 ShaderGraph 内边缘光（`FresnelEffect` 节点）；参数同 8.2。
- **粒子/VFX**：`Particle System` + `VFX Graph`（PC 档）；DoT/盾/控制提示符用 ShaderGraph Unlit + 形状贴图。
- **管线**：URP Forward+（PC）降配 Forward（移动）；SRP Batcher / GPU Instancing 开启（待 G2 冻结）。
