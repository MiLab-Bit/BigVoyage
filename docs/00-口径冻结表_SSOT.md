## 2. 已冻结硬参数

### 2.1 战斗护栏

| 键 | 值 | 说明 |
|---|---|---|
| `RESTRAINT` | **1.3** | 克制方最终伤害 ×1.3（文案可写「约 +30%」，数学一律写 ×1.3） |
| `RESTRAINT_DISADV` | **1/1.3** | 被克方最终伤害 ×(1/1.3)（对称环；≈0.76923） |
| `DOT_APPLIES_RESTRAINT` | **true** | DoT 与直击同样乘 restraintCoef |
| `STAT_CAP` | `{atk:200, def:200}` | 单卡数值天花板 |
| `SAME_SYS_SOFT_CAP` | 4 | 同体系 ≤4/5 槽 |
| `FLEET_CAPACITY` / `FLEET_SLOTS` | 10 / 5 | COST 与槽位 |

### 2.2 体力与掉落

| 键 | 值 | 说明 |
|---|---|---|
| `STAMINA_MAX` | **120** | 日行动预算；**正式=`daily_00_clear`**（0 点刷新并清空） |
| `STAMINA_REGEN_PER_MIN` | DEMO_ONLY | 仅本地联调；非正式口径 |
| `SEASON_DAYS` | **90** | 正式赛季日历；UP 池 21 天×约 4 轮；经济压测可用 30 步压缩 |
| `POI_DROP_CREW_RATE` | **1/480** | 船员卡（禁止再写 1/20） |
| `POI_DROP_SHIP_RATE` | **1/960** | 船图纸（禁止再写 1/40） |

### 2.3 商业化主轴与保底

| 项 | 冻结值 |
|---|---|
| **主商业化** | **船员 / 角色 gacha**（战斗属性与命座机制） |
| **辅助商业化** | 体力补充、资源礼包、皮肤/外观、月卡/战令 |
| **角色池小保底** | **70** 抽（50/50 UP） |
| **角色池大保底** | **140** 抽（`PITY_HARD = 140`） |
| **舰装/武器池** | 60 小 / 120 大 + 定轨 |
| **满命锚定** | 方案 C：**≈ ¥15,000**（C6 最坏 7×140=980 抽） |
| **硬货币** | **航海晶**（链上符号可写作 `$TIDE`，二者同指） |
| **软货币** | **琥珀币**（不可直购、不链上流通） |

> **作废口径**：硬保底 120 / 限定 60；「付费补体力 = 主商业化 / 强 sink」；满命 ¥50,000（方案 A 已废）。

### 2.4 皮肤与战力红线

| 项 | 冻结值 |
|---|---|
| 外观皮肤（立绘/特效/框） | **0 战力、0 进战斗公式** |
| 资源向皮肤/岛屿装饰 | **仅**资源产出或仓容，加成上限 `RESOURCE_SKIN_CAP_BONUS = 0.30`；**永不**改 `RESTRAINT` / 不进伤害公式 |
| 属性来源白名单 | ① 船员卡 ② 升星/命座 ③ 船体/舰装（受 `GEAR_STAT_CAP`）④ 环境修正 |

### 2.5 地理 vs 体系（禁止混称）

| 层 | 冻结用语 |
|---|---|
| **地理（可出航占岛）** | **三海域**：冻洋·高加索 / 渊海·亚特兰蒂斯 / 瀚海·中华；另加 **信风带**（跨海航路，非第 4 片 12 岛海域） |
| **岛数** | 全量 **36 岛**（每海 12）；Demo **单海 12 岛（冻洋）** |
| **战斗体系** | **四体系**：烈焰 → 铁壁 → 疾风 → 潮汐 → 烈焰 |
| **绑定** | 冻洋→铁壁；瀚海→烈焰；渊海→潮汐；信风带→疾风 |
| **禁用** | 单独写「四海」而不加注；「熔海/风海/潮海」作地理正式名（旧别名见下） |

**旧别名对照（仅兼容阅读，新稿禁用）**：熔海≈瀚海；潮海≈渊海；风海≈信风带。

### 2.6 付费哲学（A 决策修订文案）

> **付费买：角色获取与命座机制深度、养成效率、外观与行动便利。**  
> **不买：绕过克制环、突破 `STAT_CAP`、皮肤战斗特权。**  
> gacha 会给出战斗属性，但强度被克制环 + 天花板锁死；「机制不数值」指**不靠数值碾压破局**，不是「付费零属性」。
