## 1. 核心主题与情感曲线

### 1.1 一句话母题
**「守卫记得的不只是海，还有我们曾怎样对待它。」**——S1 回答「洋流在挑选谁配做它的孩子」，S2 回答「当孩子长大，守护者便回来要一个交代」。S2 是幸存者从「被托付的顺流者」变成「要与守护者平视的主权者」的身份转变。

### 1.2 三大主题
1. **守护与统治的边界**：核心岛★守卫苏醒后，玩家要的是「主权」还是「共存」？占岛税收从 ≤5% 的道德题，升级为「守卫是否认可你的统治」的叙事题。呼应 S1 伏笔「先驱的挑选标准」——行为（剥削/节制）影响守卫态度。
2. **记忆即审判**：守卫「记得」共主时代——正是共主抽干潮汐之核招致大沉没。S2 让玩家从守卫记忆里看见大沉没的「另一面」（守护者视角），重新理解海皇的愤怒不是恶意，而是失职之怒。
3. **墙的两面**：逆风盛行的铁壁主题下，守卫筑起「逆风之墙」护岛——它是保护，也是囚笼。S2 逼问：你是要墙内的安全，还是墙外的自由？

### 1.3 情感曲线（七章）
`肃穆`(睁眼) → `试探`(边界) → `共契`(守约) → `震撼`(记忆) → `犹疑`(逆风之墙) → `壮烈`(主权) → `余韵`(纪元)
- 设计意图：S1 末是「希望+悬念」，S2 开篇承接悬念转肃穆；中段以「守卫记忆」制造世界观震撼（补齐大沉没另一面），末段夺主权既有壮烈也有代价感，收束给 S3「海皇先驱归来」留钩。

## 2. 三层戏剧冲突

| 层级 | 冲突 | 载体 | S2 落点 |
|---|---|---|---|
| L1 人与守卫 | 玩家 vs 苏醒的核心岛守卫（试探 / 对抗 / 共鸣） | 核心岛★ PVE / 主权争夺 | Ch2 边界试探；Ch4 记忆之潮；Ch6 主权决战 |
| L2 海与守卫 | 三海 vs 守卫的「公平审判」（行为影响态度） | 中立岛争夺 / 跨海协作 | Ch3 三海守约；Ch5 逆风之墙 |

## 3. 角色谱

### 3.1 玩家（你 = 主权候选人）
- 身份：S1 末的「顺流者 / 潮汐之核持有者的同盟一员」，S2 升格为「核心岛主权候选人」。开局已持 S1 继承的科技与 NFT。
- 叙事功能：玩家对守卫的态度（税收/掠夺/共存）通过环境反馈可感——剥削会招致守卫敌意（PVE 难度↑、NPC 评语转冷），节制则触发守卫「认可」剧情。

### 3.2 三海 NPC 领袖（延续 S1，S2 各有守卫线）
| 海域 | 领袖 | S2 主线职责 |
|---|---|---|
| 冻洋·高加索 | **霜须长老·瓦兰** | Ch1 主张「逆风者方配永冻城」；Ch5 主持铁壁防线对抗逆风之墙 |
| 渊海·亚特兰蒂斯 | **潮音祭司·伊澜** | Ch4 读守卫记忆，揭示大沉没另一面；Ch6 与守卫王共鸣 |
| 瀚海·中华 | **市舶使·沈娘** | Ch2 在中立岛建立贸易前哨；Ch3 主导三海守约物资 |

### 3.3 苏醒守卫（S2 核心新角色）
- **霜铸守卫（永冻城）**：铁壁型，沉默重装，记忆封印在冰层。台词内核：「墙在，城在。墙破，则永冻归渊。」
- **渊眠守卫（亚特核心）**：潮汐型，低吟如潮，记得大沉没全貌。台词内核：「我们睡去，是为忘了你们曾怎样醒来。」
- **炎枢守卫（华夏枢）**：烈焰型，炽言务实，护火种与市舶。台词内核：「枢机不转，海路不通。谁主枢，谁先过冬。」
- **守卫王·长堤（The Tidebound Warden）**：S2 大型 Boss。三守卫之共主、先驱意志的「守门人」。非敌非友，是「试炼的具象」。台词内核：「吾等醒来，不为夺回，而为交还——若你们配。」
- **次级苏醒守卫**（中型 Boss ×4）：霜铸守卫星 / 渊眠回响 / 炎枢炬灵 / 长堤之影，按海域与周次轮换。

### 3.4 反派 / 威胁（延续）
- **海皇先驱（The Tideborn Herald）**：S1 大型 Boss，S2 以「意志残响」形式存在（VO / 记忆投影），是守卫王行为的幕后依据；正式回归见 S3。
- **中立岛争夺者**（其他联盟 / 散人）：Ch2 起成为活体冲突源。

### 3.5 中立 / 功能性
- **潮汐罗盘**：S2 新增「守卫刻度」——指针随玩家行为在「认可 / 警戒」间偏移，承担 UI 叙事。
- **自由航海者**：Boss 协作方，S2 叙事上代表「无旗者也能赴守约」。

### ▌第一幕：守卫的征兆（Ch1–Ch2）

#### 第 1 章 · 睁眼之季（备战 D1–2）
- **场景清单**
  1. `[过场]` 序章：S1 结算夜的航标塔，三座核心岛★的守卫之眼同时彻底睁开（承接 S1 Ch7 钩子）。画外音（罗盘）：「上一季的春天，是你们挣来的。这一季，醒来的是记得你们的。」
  2. `[玩法]` S2 开局：继承结算（科技/NFT/50% 资源到账），环境主题「逆风盛行（铁壁+15%）」生效，罗盘新增「守卫刻度」。
  3. `[事件]` 三海核心岛守卫同步睁眼，全服播报：「守卫苏醒。它们，记得你们。」
  4. `[过场]` 三屏分镜：瓦兰按剑望永冻城、伊澜抚心听渊眠、沈娘点枢看华夏——异口同声：「这一季，我们要的不是岛，是它们的认可。」
- **节拍**：肃穆 → 承接 → 宣告。结尾留「守卫睁眼后，核心岛四周升起逆风之墙」。
- **关键台词**（瓦兰）：「逆风者方配永冻城。可今夜，连永冻城的墙，都为我们醒了。」
- **钩子**：守卫睁眼时，每座核心岛外围浮现一道「只有克制税收者才看得见」的微光门。
- **玩法咬合**：继承规则（§3.6）、环境主题轮转启用（§3.4 逆风盛行）、罗盘新刻度（UI 叙事）。

#### 第 2 章 · 苏醒的边界（漂流 D3–8）
- **场景清单**
  1. `[玩法]` 前 5 天顺流 / 逆风靠核心岛外围，探索 POI，遭遇次级苏醒守卫（非致命试探）。
  2. `[事件]` 世界播报：S1 的「中立岛」浮现守卫遗迹，成为三海首个争夺点。
  3. `[玩法]` 沈娘（中华线）在中立岛建贸易前哨，触发首次「中立岛争夺」（轻量 GVG 预览）。
  4. `[玩法]` 玩家对守卫的态度分支：占岛后税收设 2% / 5%？选低 → 守卫刻度向「认可」偏，外围守卫敌意↓。
  5. `[过场]` 迷雾中，霜铸守卫（永冻城）首次开口：「墙在，城在。墙破，则永冻归渊。」
- **节拍**：试探 → 摩擦 → 微光门的诱惑。中段开始有「守卫记得共主」的不安预告。
- **关键台词**（沈娘）：「中立岛不中立了——它醒了，要一个主人。那就看谁先递出的不是刀，是绸。」
- **钩子**：微光门后，守卫的「记忆碎片」隐约可见——是共主时代抽核的画面。
- **玩法咬合**：占岛规则（§4.2，税收≤5% 影响守卫态度）、POI 产出（经济 §1.1）、中立岛争夺（§4.7 预览）。

### ▌第二幕：守卫之试（Ch3–Ch5）

#### 第 3 章 · 三海守约（觉醒·前 D9–13，中型 Boss #1）
- **场景清单**
  1. `[事件]` 三座核心岛守卫同时降下「守约试炼」：三海须在同一窗口协作，方开微光门。
  2. `[过场]` 云图重现「信风之路」，旁白：「共主时代，三海本是一条守约之路。守卫，是这条路的老兵。」
  3. `[玩法]` **中型 Boss #1**（霜铸守卫星 / 渊眠回响 / 炎枢炬灵 按海域轮换），全服协作。
  4. `[玩法]` 联盟围绕「守约」重组（§4.6），跨海物资（沈娘主导）支援弱海。
  5. `[抉择]` 轻量选择：守约物资优先给「最弱海」还是「本海」？选前者 → 守卫刻度「认可」+。
- **节拍**：共契 → 第一次「三海同守约」的协作快感 → 守卫态度初转。
- **关键台词**（伊澜）：「它们不是来夺岛的。它们是来问：这一千年，你们可曾配得上我们睡去时托付的海？」
- **钩子**：守约达成，微光门开一隙——门后传来「记忆之潮」的涌动声。
- **玩法咬合**：中型 Boss 频次 D4（×4/赛季）、四体系克制（卷五 §5.2，逆风盛行铁壁+15%）。

#### 第 4 章 · 记忆之潮（觉醒·后 D14–18，中型 Boss #2）
- **场景清单**
  1. `[玩法]` 护岛者经济深化：核心岛外围产出规划、跨海贸易预热。
  2. `[过场]` 伊澜潜入渊眠守卫记忆，投影展开大沉没**另一面**——守卫曾是共主的守护者，眼睁睁看共主抽干潮汐之核，海皇震怒非因恨，而因「被托付者失职」。
  3. `[玩法]` **中型 Boss #2**（守卫记忆具象化的「渊眠回响·怒」）。
  4. `[过场]` 记忆末句：「海皇不焚人。它焚的是‘被信任却背叛信任’的自己。」
  5. `[抉择]` 玩家读记忆后反应（「悲悯」/「警醒」分支文案，不影响数值，改守卫评语）。
- **节拍**：繁荣 → 震撼（世界观补全） → 沉重。核心岛壁垒因记忆波动暂弱，主权争夺窗口将启。
- **关键台词**（伊澜）：「我们一直以为海皇是怒。错了——它是羞。它羞于自己曾把海，托给会伸手掏心的人。」
- **钩子**：记忆末句：「潮汐将涌，先驱归来——它来，不是为了沉没，是为了收回它给错的人。」
- **玩法咬合**：核心岛★产出/税收（世界观 §4）部分解锁；科技 T2–T3；贸易预热（§4.3）。

#### 第 5 章 · 逆风之墙（潮汐复苏·前 D19–21，中型 Boss #3）
- **场景清单**
  1. `[过场]` 全服事件：逆风盛行达到峰值，三座核心岛升起「逆风之墙」——铁壁屏障，既护岛也囚岛。
  2. `[事件]` 跨海域通道「将开未开」，罗盘刻度剧烈摆动（认可/警戒拉锯）。
  3. `[玩法]` **中型 Boss #3**（长堤之影，守卫王的投影），试探全服「是否配开墙」。
  4. `[玩法]` 跨海域侦察（§4.7 预览），高难 POI 凸显铁壁+环境组合技。
- **节拍**：犹疑 → 压迫 → 集结。逆风之墙制造「看得见够不着的」焦虑，留 Ch6 破墙。
- **关键台词**（瓦兰）：「墙是它们筑的，也是为我们筑的。问题不在墙，在我们要的是 shelter 还是 cage。」
- **钩子**：墙裂一缝，透出守卫王「长堤」的轮廓——它醒了，在等一个答案。
- **玩法咬合**：跨海域通道 Ch6 才正式开；中型 Boss #3；逆风盛行主题峰值。

### ▌第三幕：主权与苏醒（Ch6–Ch7）

#### 第 6 章 · 核心岛主权·守卫苏醒（高潮 D22–28，中型 #4 + 大型）
- **场景清单**
  1. `[过场]` 纪元 IV 深化：跨海域通道轰然暂开，三海特产第二次互通（寒铁/星银/丝绸 汇流成型）。
  2. `[过场]` 逆风之墙崩裂，阴影自核心岛眼升起——**守卫王·长堤**初临，合唱式三海过场 + 先驱意志残响 VO。
  3. `[玩法]` **大型 Boss · 守卫王**（全服协作），掉 **核心岛主权（传说 NFT / S2 大奖）+ 赛季大奖**。
  4. `[玩法]` **中型 Boss #4**（赛季末收尾，守卫王之影散尽）。
  5. `[玩法]` 跨海域征战正式开启（§4.7），三角贸易成型（星银硬通货）。
