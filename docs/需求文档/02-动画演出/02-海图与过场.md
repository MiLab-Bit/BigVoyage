# 02-02 · 海图 / 航行 / 过场动画（Godot）

---

## 1. 海图交互动画 · P0

| 动作 | 表现 | Godot |
|---|---|---|
| 平移/缩放 | 惯性阻尼；缩放锚点=光标 | `Camera2D` drag + wheel |
| 选岛 | 图标弹跳 0.15s + 铜边亮 | `Tween` scale |
| 迷雾揭开 | 雾 alpha 溶解 0.6–1.0s，露出剪影→实岛 | shader / `AnimationPlayer` |
| 出航 | 船图标沿邻接边贝塞尔移动；时长∝边权 | `Path2D` 或逐点 Tween |
| 靠岸 | 短停顿 + 锚点下落 | 接 `sfx_nav_anchor` |
| 日切 | 天空/滤镜短 crossfade；UI「第 N 日」 | `CanvasModulate` |
| 主权易手 | 旗幟变色 + 落旗 0.4s | 换 `icon_flag_*` |
| 敌情预警 | 岛缘红脉冲 | 接 intensity→1 音乐 |

## 3. 叙事过场 · P1（Demo 可静态幻灯）

| 类型 | 需求 | 时长 |
|---|---|---|
| 章节标题 | 羊皮纸+铜字淡入；`sfx_nar_chapter_title` | 2–3s |
| 领袖对话 | 立绘滑入 + 字幕；2D **无口型** | 按 VO |
| Boss 降临 | 尺度反差构图推近；全编制 stinger | ≤6s |
| 记忆/梦境 | 低对比+波纹 shader；`sfx_nar_whisper` | 可跳过 |

Godot：`ColorRect` 转场 / `AnimationPlayer` 时间轴；过场场景独立 `Cutscene.tscn`。
